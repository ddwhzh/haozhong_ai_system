## 2. ScoringFunction详细设计

### 2.1 类结构

```python
class ScoringFunction:
    def __init__(
        self,
        sparse_weight: float = 0.3,
        denoising_strength: float = 0.1,
    ) -> None:
        self.sparse_weight = sparse_weight
        self.dense_weight = 1.0 - sparse_weight
        self.denoising_strength = denoising_strength
```

### 2.2 score() 方法

**功能**: 计算单个查询-文档对的混合评分

**输入**:
- `query_embedding`: List[float] - 查询嵌入向量
- `doc_embedding`: List[float] - 文档嵌入向量
- `query_tokens`: List[str] - 查询分词结果
- `doc_tokens`: List[str] - 文档分词结果

**输出**: Dict[str, float]
```python
{
    "dense_score": float,        # 密集向量分数 [0, 1]
    "sparse_score": float,       # 稀疏矩阵分数 [0, 1]
    "combined_score": float,     # 混合分数 [0, 1]
    "asymmetry_factor": float    # 不对称因子 [0, 1]
}
```

**伪代码**:
```
function score(query_embedding, doc_embedding, query_tokens, doc_tokens):
    // 1. 计算密集向量分数 (带去噪)
    dense_score = _denoised_cosine(query_embedding, doc_embedding)
    
    // 2. 计算稀疏矩阵分数 (非对称)
    sparse_score = _sparse_score(query_tokens, doc_tokens)
    
    // 3. 计算混合分数
    combined_score = dense_weight × dense_score + sparse_weight × sparse_score
    
    // 4. 计算不对称因子
    reverse_sparse = _sparse_score(doc_tokens, query_tokens)
    asymmetry_factor = |sparse_score - reverse_sparse|
    
    return {
        dense_score: round(dense_score, 4),
        sparse_score: round(sparse_score, 4),
        combined_score: round(combined_score, 4),
        asymmetry_factor: round(asymmetry_factor, 4)
    }
```

### 2.3 _denoised_cosine() 方法

**功能**: 计算带自监督去噪的余弦相似度

**算法原理**:
1. 计算两个向量的平均方向作为"噪声方向"的估计
2. 从原始向量中减去噪声分量
3. 在去噪后的向量上计算余弦相似度

**伪代码**:
```
function _denoised_cosine(embedding_a, embedding_b):
    // 转换为numpy数组
    a = np.array(embedding_a)
    b = np.array(embedding_b)
    
    // 边界检查
    if a.shape != b.shape or a.size == 0:
        return 0.0
    
    // 计算平均向量 (噪声方向估计)
    mean_vec = (a + b) / 2.0
    mean_norm = ||mean_vec||
    
    if mean_norm > 1e-10:
        // 归一化噪声方向
        noise_direction = mean_vec / mean_norm
        
        // 去噪: 移除噪声方向上的投影
        a_denoised = a - λ × (a · noise_direction) × noise_direction
        b_denoised = b - λ × (b · noise_direction) × noise_direction
        // 其中 λ = denoising_strength (默认0.1)
    else:
        a_denoised = a
        b_denoised = b
    
    // 计算余弦相似度
    norm_a = ||a_denoised||
    norm_b = ||b_denoised||
    
    if norm_a < 1e-10 or norm_b < 1e-10:
        return 0.0
    
    cosine_sim = (a_denoised · b_denoised) / (norm_a × norm_b)
    return cosine_sim
```

**数学公式**:
```
noise_direction = normalize((embedding_a + embedding_b) / 2)
a_denoised = embedding_a - λ × (embedding_a · noise_direction) × noise_direction
b_denoised = embedding_b - λ × (embedding_b · noise_direction) × noise_direction
cosine_sim = (a_denoised · b_denoised) / (||a_denoised|| × ||b_denoised||)
```

### 2.4 _sparse_score() 方法

**功能**: 计算BM25风格的非对称稀疏评分

**算法原理**:
1. 对查询中的每个唯一词项, 计算其在文档中的词频 (TF)
2. 计算逆文档频率 (IDF), 基于查询词项频率
3. 应用BM25的TF归一化公式
4. 对所有词项求和并归一化到 [0, 1]

**伪代码**:
```
function _sparse_score(query_tokens, doc_tokens):
    if query_tokens is empty or doc_tokens is empty:
        return 0.0
    
    // BM25参数
    k1 = 1.2
    b = 0.75
    
    // 计算文档词频
    doc_tf = Counter(doc_tokens)
    doc_len = len(doc_tokens)
    avg_dl = max(doc_len, 1)  // 简化: 单文档上下文
    
    score = 0.0
    
    // 遍历查询中的唯一词项
    for each unique token in query_tokens:
        tf = doc_tf[token]  // 文档中该词项的频率
        
        if tf == 0:
            continue  // 词项不在文档中, 跳过
        
        // 计算IDF (基于查询词项频率)
        query_tf = count(token in query_tokens)
        idf = log(1 + 1.0 / max(query_tf, 1))
        
        // BM25 TF归一化
        tf_norm = (tf × (k1 + 1)) / (tf + k1 × (1 - b + b × doc_len / avg_dl))
        
        score += idf × tf_norm
    
    // 归一化到 [0, 1]
    max_possible = |unique(query_tokens)| × log(2) × (k1 + 1)
    if max_possible > 0:
        score = min(score / max_possible, 1.0)
    
    return score
```

**数学公式**:
```
sparse_score = Σ_{q_i ∈ unique(query)} IDF(q_i) × TF_norm(q_i, doc)

其中:
IDF(q_i) = log(1 + 1 / TF_query(q_i))
TF_norm(q_i, doc) = (TF_doc(q_i) × (k1 + 1)) / (TF_doc(q_i) + k1 × (1 - b + b × |doc| / avg_dl))

归一化:
sparse_score_normalized = min(sparse_score / (|unique(query)| × log(2) × (k1 + 1)), 1.0)
```

**非对称性证明**:
```
score(query, doc) = Σ_{q_i} IDF_query(q_i) × TF_norm(q_i, doc)
score(doc, query) = Σ_{d_i} IDF_doc(d_i) × TF_norm(d_i, query)

由于 IDF_query(q_i) ≠ IDF_doc(d_i) 且 TF_norm 也不同,
因此 score(query, doc) ≠ score(doc, query)
```

### 2.5 batch_score() 方法

**功能**: 批量计算查询-文档对的分数矩阵

**输入**:
- `queries`: List[Dict] - 查询列表, 每个dict包含 `embedding`, `tokens`
- `documents`: List[Dict] - 文档列表, 每个dict包含 `embedding`, `tokens`

**输出**: np.ndarray - 形状为 (len(queries), len(documents)) 的分数矩阵

**伪代码**:
```
function batch_score(queries, documents):
    n_q = len(queries)
    n_d = len(documents)
    matrix = zeros((n_q, n_d))
    
    for i in range(n_q):
        for j in range(n_d):
            result = score(
                query_embedding=queries[i]["embedding"],
                doc_embedding=documents[j]["embedding"],
                query_tokens=queries[i]["tokens"],
                doc_tokens=documents[j]["tokens"]
            )
            matrix[i, j] = result["combined_score"]
    
    return matrix
```

**复杂度**: O(n_q × n_d × (E + T))
- E: 嵌入向量维度
- T: 平均词项数量

### 3.2 match() 方法

**功能**: 执行匈牙利匹配, 找到最优的预测-目标分配

**输入**:
- `predictions`: List[Dict] - 预测列表 (生成内容片段)
- `targets`: List[Dict] - 目标列表 (证据源)

**输出**: Dict
```python
{
    "matches": List[Tuple[int, int, float]],  # (pred_idx, target_idx, score)
    "unmatched_preds": List[int],              # 未匹配的预测索引
    "unmatched_targets": List[int],            # 未匹配的目标索引
    "cost_matrix": List[List[float]],          # 成本矩阵
    "score_matrix": List[List[float]],          # 分数矩阵
    "overall_score": float                     # 整体评分
}
```

**伪代码**:
```
function match(predictions, targets):
    n_pred = len(predictions)
    n_targ = len(targets)
    
    // 边界情况: 空输入
    if n_pred == 0 or n_targ == 0:
        return {
            matches: [],
            unmatched_preds: [0..n_pred-1],
            unmatched_targets: [0..n_targ-1],
            cost_matrix: [],
            overall_score: 0.0
        }
    
    // 1. 计算分数矩阵
    score_matrix = scoring_fn.batch_score(predictions, targets)
    // 形状: (n_pred, n_targ)
    
    // 2. 转换为成本矩阵 (匈牙利算法最小化成本)
    cost_matrix = 1.0 - score_matrix
    
    // 3. 执行线性分配
    row_indices, col_indices = linear_sum_assignment(cost_matrix)
    // row_indices: 匹配的预测索引
    // col_indices: 匹配的目标索引
    
    // 4. 构建匹配结果
    matches = []
    matched_preds = set()
    matched_targets = set()
    total_score = 0.0
    
    for (row, col) in zip(row_indices, col_indices):
        if row < n_pred and col < n_targ:
            match_score = score_matrix[row, col]
            matches.append((row, col, round(match_score, 4)))
            matched_preds.add(row)
            matched_targets.add(col)
            total_score += match_score
    
    // 5. 找出未匹配项
    unmatched_preds = [i for i in range(n_pred) if i not in matched_preds]
    unmatched_targets = [i for i in range(n_targ) if i not in matched_targets]
    
    // 6. 计算整体评分
    overall_score = total_score / max(len(matches), 1)
    
    return {
        matches: matches,
        unmatched_preds: unmatched_preds,
        unmatched_targets: unmatched_targets,
        cost_matrix: cost_matrix.tolist(),
        score_matrix: score_matrix.tolist(),
        overall_score: round(overall_score, 4)
    }
```

### 3.3 evaluate_faithfulness() 方法

**功能**: 基于匈牙利匹配结果评估忠实度

**输入**:
- `generated_sections`: List[Dict] - 生成内容片段列表
- `evidence_sources`: List[Dict] - 证据源列表
- `threshold`: float - 忠实度阈值 (默认0.5)

**输出**: Dict
```python
{
    "faithfulness_rate": float,                # 忠实度率
    "section_scores": List[{
        "generated_idx": int,
        "evidence_idx": int,
        "score": float,
        "is_faithful": bool
    }],
    "unmatched_sections": List[int],           # 未匹配的片段索引
    "overall_score": float                     # 整体评分
}
```

**伪代码**:
```
function evaluate_faithfulness(generated_sections, evidence_sources, threshold):
    // 1. 执行匹配
    match_result = match(generated_sections, evidence_sources)
    
    // 2. 评估每个匹配对
    faithful_count = 0
    section_scores = []
    
    for (pred_idx, targ_idx, score) in match_result["matches"]:
        is_faithful = (score >= threshold)
        
        if is_faithful:
            faithful_count += 1
        
        section_scores.append({
            generated_idx: pred_idx,
            evidence_idx: targ_idx,
            score: score,
            is_faithful: is_faithful
        })
    
    // 3. 计算忠实度率
    total = len(generated_sections)
    faithfulness_rate = faithful_count / max(total, 1)
    
    return {
        faithfulness_rate: round(faithfulness_rate, 4),
        section_scores: section_scores,
        unmatched_sections: match_result["unmatched_preds"],
        overall_score: match_result["overall_score"]
    }
```

### 3.4 linear_sum_assignment算法说明

**算法**: Kuhn-Munkres算法 (匈牙利算法)

**输入**: 成本矩阵 `cost_matrix` (n×m)

**输出**: `row_indices`, `col_indices` - 最优分配的行列索引

**算法步骤** (简化):
```
1. 初始化: 创建n×m的成本矩阵
2. 行约简: 每行减去该行最小值
3. 列约简: 每列减去该列最小值
4. 覆盖零: 用最少的行/列覆盖所有零
5. 调整矩阵: 如果覆盖数 < min(n,m), 调整矩阵并重复步骤4
6. 分配: 找到覆盖所有零的最优分配
```

**复杂度**: O(n³), 其中 n = max(n_pred, n_targ)

**实现**: 使用 `scipy.optimize.linear_sum_assignment`, 该函数使用Jonker-Volgenant算法, 复杂度为O(n³)

async function optimize(evaluation_results, evidence_graph, current_prompts):
    // 1. 识别弱项片段
    weak_sections = _identify_weak_sections(evaluation_results)
    
    if weak_sections is empty:
        logger.info("auto_prompt_no_weak_sections")
        return []
    
    // 2. 生成优化建议
    try:
        proposals = await _generate_optimizations(weak_sections, current_prompts)
    except Exception as e:
        logger.error("auto_prompt_generation_failed", error=str(e))
        return []
    
    // 3. 创建优化节点
    optimization_nodes = []
    for each proposal in proposals:
        node = evidence_graph.add_evidence(
            evidence=Evidence(
                content=json.dumps(proposal),
                content_type="prompt_optimization",
                source="auto_prompt_optimizer",
                metadata={
                    diagnosis: proposal["diagnosis"],
                    target: proposal["target"],
                    expected_improvement: proposal["expected_improvement"]
                }
            ),
            belief=Belief(
                content=f"Prompt optimization: {proposal['diagnosis']}",
                confidence=proposal["expected_improvement"],
                source_agent="evaluation_agent"
            ),
            intent=Intent(
                intent_type=OPTIMIZE_PROMPT,
                description=f"Auto prompt optimization targeting {proposal['target']}",
                parameters={
                    target: proposal["target"],
                    diagnosis: proposal["diagnosis"]
                },
                source_agent="evaluation_agent"
            ),
            tags=["prompt_optimization", proposal["target"]]
        )
        optimization_nodes.append(node)
    
    logger.info("auto_prompt_proposals_generated", count=len(optimization_nodes))
    return optimization_nodes
```

### 4.3 _identify_weak_sections() 方法

**功能**: 从评估结果中识别弱项片段

**伪代码**:
```
function _identify_weak_sections(evaluation_results):
    weak = []
    section_scores = evaluation_results["section_scores"]
    
    // 1. 识别低分或不忠实的片段
    for each section in section_scores:
        if not section["is_faithful"] or section["score"] < 0.5:
            weak.append({
                section_idx: section["generated_idx"],
                score: section["score"],
                is_faithful: section["is_faithful"]
            })
    
    // 2. 标记未匹配的片段
    for idx in evaluation_results["unmatched_sections"]:
        weak.append({
            section_idx: idx,
            score: 0.0,
            is_faithful: False,
            issue: "unmatched"
        })
    
    return weak
```

### 4.4 _generate_optimizations() 方法

**功能**: 使用LLM生成提示词优化建议

**伪代码**:
```
async function _generate_optimizations(weak_sections, current_prompts):
    // 1. 准备输入数据
    weak_summary = json.dumps(weak_sections, indent=2)
    prompt_summary = json.dumps(
        {k: v[:200] + "..." for k, v in current_prompts.items()},
        indent=2
    ) if current_prompts else "(no current prompts provided)"
    
    // 2. 构建LLM消息
    messages = [
        SystemMessage(content=load_prompt("auto_prompt_system")),
        HumanMessage(content=(
            f"Weak sections from evaluation:\n{weak_summary}\n\n"
            f"Current prompts (truncated):\n{prompt_summary}"
        ))
    ]
    
    // 3. 调用LLM
    response = await llm_service.call(messages, prompt_name="auto_prompt_system")
    content = response.content.strip()
    
    // 4. 解析JSON响应
    if "```" in content:
        // 提取代码块中的JSON
        content = content.split("```")[1]
        if content.startswith("json"):
            content = content[4:]
        content = content.strip()
    
    // 5. 解析JSON
    try:
        parsed = json.loads(content)
        return parsed if isinstance(parsed, list) else [parsed]
    except json.JSONDecodeError:
        // 解析失败, 返回默认结构
        return [{
            diagnosis: "parse_error",
            prompt_patch: content,
            expected_improvement: 0.3,
            target: "general"
        }]
```

### 5.2 _execute() 方法

**功能**: 执行完整的评估流程

**伪代码**:
```
async function _execute(agent_input):
    evidence_graph = agent_input.evidence_graph
    query = agent_input.query
    
    logger.info("evaluation_pipeline_start", query=query)
    
    // 1. 收集生成内容和证据节点
    generated_nodes = filter nodes where content_type == "generated_content"
    evidence_nodes = filter nodes where content_type in [
        "fused_evidence", "document_chunk", "kg_match", "reasoning_chain"
    ]
    
    if generated_nodes is empty:
        return AgentOutput(
            status=NEEDS_MORE_INFO,
            error_message="No generated content to evaluate"
        )
    
    // 2. 准备匹配数据 (嵌入、分词)
    gen_dicts = await _prepare_for_matching(generated_nodes)
    evi_dicts = await _prepare_for_matching(evidence_nodes)
    
    // 3. 匈牙利匹配评估
    eval_result = matcher.evaluate_faithfulness(
        generated_sections=gen_dicts,
        evidence_sources=evi_dicts,
        threshold=EVALUATION_CONFIDENCE_THRESHOLD
    )
    
    // 4. 创建评估结果节点
    eval_node = evidence_graph.add_evidence(
        evidence=Evidence(
            content=json.dumps(eval_result),
            content_type="evaluation_result",
            source="evaluation_agent",
            metadata={
                faithfulness_rate: eval_result["faithfulness_rate"],
                overall_score: eval_result["overall_score"],
                sections_evaluated: len(generated_nodes)
            }
        ),
        belief=Belief(
            content=f"Evaluation: faithfulness={eval_result['faithfulness_rate']:.2f}",
            confidence=eval_result["overall_score"],
            source_agent="evaluation_agent"
        ),
        intent=Intent(
            intent_type=EVALUATE,
            description="Hungarian matching faithfulness evaluation",
            parameters=eval_result,
            source_agent="evaluation_agent"
        ),
        parent_node_ids=[n.node_id for n in generated_nodes],
        relation=EVALUATED_BY,
        tags=["evaluation"]
    )
    
    new_nodes = [eval_node]
    belief_updates = []
    
    // 5. 更新生成节点的信念
    for each section in eval_result["section_scores"]:
        gen_idx = section["generated_idx"]
        if gen_idx < len(generated_nodes):
            gen_node = generated_nodes[gen_idx]
            belief_updates.append(BeliefUpdate(
                target_belief_id=gen_node.belief.belief_id,
                new_confidence=section["score"],
                reason=f"Evaluation score: {section['score']:.3f}, faithful={section['is_faithful']}",
                proposed_by="evaluation_agent"
            ))
    
    // 6. 自动提示词优化 (如果质量低于阈值)
    overall_score = eval_result["overall_score"]
    if overall_score < EVALUATION_CONFIDENCE_THRESHOLD:
        logger.info("auto_prompt_triggered", overall_score=overall_score)
        prompt_nodes = await auto_prompt.optimize(
            evaluation_results=eval_result,
            evidence_graph=evidence_graph
        )
        new_nodes.extend(prompt_nodes)
    
    // 7. 确定状态
    status = SUCCESS if overall_score >= EVALUATION_CONFIDENCE_THRESHOLD else PARTIAL
    
    logger.info("evaluation_pipeline_complete", ...)
    
    return AgentOutput(
        agent_name="evaluation_agent",
        status=status,
        new_nodes=new_nodes,
        belief_updates=belief_updates,
        summary=f"Evaluation complete: overall_score={overall_score:.3f}, ...",
        metrics={
            overall_score: overall_score,
            faithfulness_rate: eval_result["faithfulness_rate"],
            sections_evaluated: len(generated_nodes),
            belief_updates: len(belief_updates),
            prompt_optimizations: len(new_nodes) - 1
        }
    )
```

### 5.3 _prepare_for_matching() 方法

**功能**: 为匹配准备节点数据 (嵌入、分词)

**伪代码**:
```
async function _prepare_for_matching(nodes):
    dicts = []
    
    for each node in nodes:
        content = node.evidence.content
        tokens = content.lower().split()
        
        try:
            embedding = await embeddings.aembed_query(content[:8000])
        except Exception:
            embedding = []  // 嵌入失败, 使用空向量
        
        dicts.append({
            id: node.node_id,
            content: content,
            tokens: tokens,
            embedding: embedding
        })
    
    return dicts
```

**注意**: 
- 内容截断到8000字符 (OpenAI嵌入限制)
- 嵌入失败时使用空向量, 依赖稀疏评分

## 6. 错误处理详细设计

### 6.1 异常分类

#### 6.1.1 输入验证异常
- **场景**: 无生成内容节点
- **处理**: 返回 `AgentStatus.NEEDS_MORE_INFO`
- **日志**: `evaluation_pipeline_start` + 错误消息

#### 6.1.2 嵌入生成异常
- **场景**: OpenAI API调用失败
- **处理**: 使用空嵌入向量 `[]`, 继续执行
- **日志**: 警告级别日志
- **影响**: 仅依赖稀疏评分, 可能降低准确性

#### 6.1.3 矩阵计算异常
- **场景**: 矩阵维度不匹配或数值溢出
- **处理**: 返回空匹配结果, overall_score = 0
- **日志**: 错误级别日志 + 异常堆栈

#### 6.1.4 LLM调用异常
- **场景**: 提示词优化LLM调用失败
- **处理**: 返回空优化提案列表
- **日志**: 错误级别日志
- **影响**: 不影响评估结果, 仅缺少优化建议

#### 6.1.5 JSON解析异常
- **场景**: LLM返回的JSON格式错误
- **处理**: 将原始内容作为 `prompt_patch`, 使用默认值
- **日志**: 警告级别日志
- **降级**: 返回单个优化提案, `expected_improvement = 0.3`

### 6.2 错误恢复策略

1. **部分失败容忍**: 嵌入失败不影响整体流程
2. **默认值降级**: JSON解析失败使用默认结构
3. **空结果返回**: 匹配失败返回空结果而非异常
4. **日志记录**: 所有异常都记录详细日志

## 7. 性能优化详细设计

### 7.1 批量处理优化

**问题**: 循环调用 `score()` 效率低

**解决方案**: `batch_score()` 批量计算

**优化效果**:
- 减少函数调用开销
- 利用numpy向量化运算
- 预分配矩阵内存

### 7.2 异步I/O优化

**问题**: 嵌入生成是阻塞操作

**解决方案**: 使用 `async/await` 和 `aembed_query()`

**优化效果**:
- 并发处理多个嵌入请求
- 不阻塞其他操作

### 7.3 矩阵运算优化

**技术**:
- 使用 `numpy` 进行向量化计算
- 避免Python循环
- 预分配内存

**示例**:
```python
# 低效: Python循环
for i in range(n):
    for j in range(m):
        matrix[i, j] = compute_score(i, j)

# 高效: 向量化
matrix = np.zeros((n, m))
# 批量计算 (在batch_score中实现)
```

### 7.4 缓存策略

**可缓存内容**:
- 嵌入向量 (相同内容)
- 评分结果 (相同输入对)

**缓存键**:
- 嵌入: `hash(content)`
- 评分: `hash((query_content, doc_content))`

**实现位置**: 可在 `ScoringFunction` 中添加缓存装饰器
