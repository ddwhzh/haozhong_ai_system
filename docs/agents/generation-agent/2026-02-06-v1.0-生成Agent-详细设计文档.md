## 2. ProposalDecomposer详细设计

### 2.1 算法流程

#### 2.1.1 主流程算法

```
Algorithm: generate_proposals
Input: query (str), evidence_graph (EvidenceGraph)
Output: List[EvidenceNode]

1. high_conf_nodes ← evidence_graph.get_high_confidence_nodes(threshold=0.3)
2. evidence_summary ← _summarize_evidence(high_conf_nodes)
3. evidence_stats ← _count_evidence_types(evidence_graph)
4. 
5. TRY:
6.     proposals ← _llm_propose(query, evidence_summary, evidence_stats)
7. EXCEPT Exception as e:
8.     logger.error("proposal_generation_failed", error=str(e))
9.     proposals ← [_fallback_proposal(query)]
10.
11. proposal_nodes ← []
12. FOR i, prop IN enumerate(proposals):
13.     aspect ← prop.get("aspect", "general")
14.     question ← prop.get("question", "")
15.     slots ← prop.get("slots", [])
16.     
17.     node ← evidence_graph.add_evidence(
18.         evidence=Evidence(
19.             content=json.dumps(prop),
20.             content_type="proposal",
21.             source="proposal_decomposer",
22.             metadata={
23.                 "aspect": aspect,
24.                 "question": question,
25.                 "slot_count": len(slots),
26.                 "priority": prop.get("priority", 3),
27.                 "index": i
28.             }
29.         ),
30.         belief=Belief(confidence=0.85, ...),
31.         intent=Intent(intent_type=IntentType.PROPOSE_PLAN, ...),
32.         parent_node_ids=[],
33.         tags=["proposal", aspect]
34.     )
35.     proposal_nodes.append(node)
36.
37. logger.info("proposals_generated", count=len(proposal_nodes), ...)
38. RETURN proposal_nodes
```

#### 2.1.2 证据汇总算法

```
Algorithm: _summarize_evidence
Input: nodes (List[EvidenceNode])
Output: str

1. IF nodes is empty:
2.     RETURN "(no evidence available)"
3.
4. parts ← []
5. FOR node IN nodes[:15]:  // 最多15个节点
6.     conf ← node.belief.confidence
7.     ctype ← node.evidence.content_type
8.     content ← node.evidence.content[:150]  // 截取前150字符
9.     parts.append("[%s conf=%.2f] %s" % (ctype, conf, content))
10.
11. RETURN "\n---\n".join(parts)
```

#### 2.1.3 证据类型统计算法

```
Algorithm: _count_evidence_types
Input: evidence_graph (EvidenceGraph)
Output: Dict[str, int]

1. counts ← {}
2. FOR node IN evidence_graph.nodes.values():
3.     ct ← node.evidence.content_type
4.     counts[ct] ← counts.get(ct, 0) + 1
5. RETURN counts
```

#### 2.1.4 LLM Proposal生成算法

```
Algorithm: _llm_propose
Input: query (str), evidence_summary (str), evidence_stats (Dict[str, int])
Output: List[Dict[str, Any]]

1. stats_text ← ", ".join("%s=%s" % (k, v) for k, v in evidence_stats.items())
2. 
3. messages ← [
4.     SystemMessage(content=load_prompt("proposal_decompose_system", max_proposals=self.max_proposals)),
5.     HumanMessage(content="User Query: %s\n\nEvidence stats: %s\n\nEvidence:\n%s" % (query, stats_text, evidence_summary))
6. ]
7. 
8. response ← await llm_service.call(messages, prompt_name="proposal_decompose_system")
9. content ← response.content.strip()
10. 
11. // 提取JSON (处理markdown代码块)
12. IF "```" IN content:
13.     content ← content.split("```")[1]
14.     IF content.startswith("json"):
15.         content ← content[4:]
16.     content ← content.strip()
17. 
18. parsed ← json.loads(content)
19. 
20. IF isinstance(parsed, list):
21.     RETURN parsed[:self.max_proposals]  // 限制数量
22. ELSE:
23.     RETURN [_fallback_proposal(query)]
```

#### 2.1.5 Fallback Proposal生成算法

```
Algorithm: _fallback_proposal
Input: query (str)
Output: Dict[str, Any]

1. RETURN {
2.     "aspect": "comprehensive",
3.     "question": query,
4.     "slots": [
5.         {"name": "core_answer", "description": "Direct answer", "evidence_hint": "fused_evidence"},
6.         {"name": "key_points", "description": "2-3 key points", "evidence_hint": "fused_evidence"},
7.         {"name": "context", "description": "Background info", "evidence_hint": "document_chunk"}
8.     ],
9.     "priority": 1
10. }
```

### 2.2 数据结构

#### 2.2.1 Proposal JSON结构

```python
{
    "aspect": str,           # 必填, 如"定义"、"组件"、"应用"
    "question": str,         # 必填, 该方面的具体问题
    "slots": [              # 必填, slot列表
        {
            "name": str,                    # Slot名称
            "description": str,            # Slot描述
            "evidence_hint": str           # 证据类型提示
        },
        ...
    ],
    "priority": int         # 必填, 1-5, 1为最高
}
```

#### 2.2.2 Proposal Node结构

```python
EvidenceNode(
    node_id: str,
    evidence=Evidence(
        content: str,                    # Proposal JSON字符串
        content_type: "proposal",
        source: "proposal_decomposer",
        metadata={
            "aspect": str,
            "question": str,
            "slot_count": int,
            "priority": int,
            "index": int
        }
    ),
    belief=Belief(
        content: str,                    # "Proposal [aspect]: [question]"
        confidence: 0.85,
        source_agent: "generation_agent"
    ),
    intent=Intent(
        intent_type: IntentType.PROPOSE_PLAN,
        description: str,
        parameters={
            "aspect": str,
            "slot_count": int,
            "priority": int
        },
        source_agent: "generation_agent"
    ),
    parent_node_ids: [],
    tags: ["proposal", aspect]
)
```

### 2.3 错误处理

#### 2.3.1 LLM调用失败

**错误类型**: Exception (网络错误、超时、API错误等)

**处理策略**:
```python
try:
    proposals = await self._llm_propose(...)
except Exception as e:
    logger.error("proposal_generation_failed", error=str(e))
    proposals = [self._fallback_proposal(query)]
```

**影响**: 使用fallback proposal继续执行, 不影响整体流程

#### 2.3.2 JSON解析失败

**错误类型**: json.JSONDecodeError

**处理策略**: 在`_llm_propose`中, 如果`json.loads()`失败, 返回fallback proposal

**影响**: 使用fallback proposal继续执行

#### 2.3.3 返回非列表格式

**错误类型**: 逻辑错误 (LLM返回dict而非list)

**处理策略**: 检查`isinstance(parsed, list)`, 如果不是列表, 返回fallback proposal

**影响**: 使用fallback proposal继续执行

## 3. ContentGenerator详细设计

### 3.1 算法流程

#### 3.1.1 主流程算法

```
Algorithm: generate
Input: proposal_nodes (List[EvidenceNode]), evidence_graph (EvidenceGraph), query (str)
Output: List[EvidenceNode]

1. generated_nodes ← []
2. 
3. // 按priority排序 (priority越小越靠前)
4. sorted_proposals ← sorted(
5.     proposal_nodes,
6.     key=lambda n: n.evidence.metadata.get("priority", 3)
7. )
8. 
9. FOR prop_node IN sorted_proposals:
10.     TRY:
11.         gen_node ← await _extract_for_proposal(prop_node, evidence_graph, query)
12.         IF gen_node is not None:
13.             generated_nodes.append(gen_node)
14.     EXCEPT Exception as e:
15.         logger.error(
16.             "slot_extraction_failed",
17.             proposal_aspect=prop_node.evidence.metadata.get("aspect"),
18.             error=str(e)
19.         )
20.         // 跳过该proposal, 继续处理其他
21. 
22. logger.info("slot_extraction_complete", count=len(generated_nodes))
23. RETURN generated_nodes
```

#### 3.1.2 单个Proposal提取算法

```
Algorithm: _extract_for_proposal
Input: proposal_node (EvidenceNode), evidence_graph (EvidenceGraph), query (str)
Output: EvidenceNode | None

1. // 解析Proposal JSON
2. TRY:
3.     proposal ← json.loads(proposal_node.evidence.content)
4. EXCEPT json.JSONDecodeError:
5.     // Fallback: 构造简单proposal
6.     proposal ← {
7.         "aspect": "general",
8.         "question": proposal_node.evidence.content,
9.         "slots": [{"name": "content", "description": "Main content", "evidence_hint": "any"}]
10.     }
11. 
12. aspect ← proposal.get("aspect", "general")
13. question ← proposal.get("question", "")
14. slots ← proposal.get("slots", [])
15. 
16. // 根据evidence_hint匹配证据节点
17. evidence_by_hint ← _gather_evidence_by_hint(evidence_graph, slots)
18. evidence_text ← _format_evidence_for_extraction(evidence_by_hint)
19. 
20. // 格式化slots描述
21. slots_desc ← json.dumps(slots, ensure_ascii=False, indent=2)
22. 
23. // LLM提取
24. messages ← [
25.     SystemMessage(content=load_prompt("slot_extraction_system")),
26.     HumanMessage(content=(
27.         "Original Query: %s\n\n"
28.         "Proposal Aspect: %s\n"
29.         "Proposal Question: %s\n\n"
30.         "Slots to fill:\n%s\n\n"
31.         "Available Evidence:\n%s"
32.     ) % (query, aspect, question, slots_desc, evidence_text))
33. ]
34. 
35. response ← await llm_service.call(messages, prompt_name="slot_extraction_system")
36. raw ← response.content.strip()
37. 
38. // 解析filled slots
39. filled_slots ← _parse_filled_slots(raw)
40. 
41. // 生成readable content
42. readable_content ← _slots_to_readable(aspect, question, filled_slots)
43. 
44. // 计算平均confidence
45. confidences ← [
46.     v.get("confidence", 0.5) 
47.     FOR v IN filled_slots.values()
48.     IF isinstance(v, dict) AND v.get("value") is not None
49. ]
50. avg_confidence ← sum(confidences) / len(confidences) IF confidences ELSE 0.3
51. 
52. // 创建Generated Content Node
53. node ← evidence_graph.add_evidence(
54.     evidence=Evidence(
55.         content=readable_content,
56.         content_type="generated_content",
57.         source="content_generator",
58.         metadata={
59.             "aspect": aspect,
60.             "question": question,
61.             "filled_slots": filled_slots,
62.             "slot_count": len(slots),
63.             "filled_count": sum(
64.                 1 FOR v IN filled_slots.values()
65.                 IF isinstance(v, dict) AND v.get("value") is not None
66.             ),
67.             "evidence_count": sum(len(v) FOR v IN evidence_by_hint.values())
68.         }
69.     ),
70.     belief=Belief(
71.         content="Generated content for [%s]: %s" % (aspect, question),
72.         confidence=min(avg_confidence, 1.0),
73.         source_agent: "generation_agent"
74.     ),
75.     intent=Intent(
76.         intent_type: IntentType.GENERATE,
77.         description: "Slot-filled content for: %s" % aspect,
78.         parameters={"aspect": aspect},
79.         source_agent: "generation_agent"
80.     ),
81.     parent_node_ids=[proposal_node.node_id],
82.     relation=EdgeRelation.DERIVED_FROM,
83.     tags=["generated", aspect, "slot_filled"]
84. )
85. 
86. RETURN node
```

#### 3.1.3 证据匹配算法

```
Algorithm: _gather_evidence_by_hint
Input: evidence_graph (EvidenceGraph), slots (List[Dict[str, Any]])
Output: Dict[str, List[EvidenceNode]]

1. all_nodes ← list(evidence_graph.nodes.values())
2. result ← {}
3. 
4. // Hint到Tags的映射
5. hint_to_tags ← {
6.     "fused_evidence": ["fused"],
7.     "kg_match": ["kg_chain", "kg_match"],
8.     "document_chunk": ["vector_result"]
9. }
10. 
11. FOR slot IN slots:
12.     hint ← slot.get("evidence_hint", "any")
13.     
14.     IF hint NOT IN result:
15.         matching_tags ← hint_to_tags.get(hint, [])
16.         
17.         IF matching_tags:
18.             // 匹配特定tags
19.             result[hint] ← [
20.                 n FOR n IN all_nodes
21.                 IF any(t IN n.tags FOR t IN matching_tags)
22.                 AND n.belief.confidence >= 0.2
23.             ]
24.         ELSE:
25.             // "any"类型: 排除proposal类型
26.             result[hint] ← [
27.                 n FOR n IN all_nodes
28.                 IF n.evidence.content_type NOT IN ("proposal",)
29.                 AND n.belief.confidence >= 0.2
30.             ]
31. 
32. RETURN result
```

#### 3.1.4 证据格式化算法

```
Algorithm: _format_evidence_for_extraction
Input: evidence_by_hint (Dict[str, List[EvidenceNode]])
Output: str

1. parts ← []
2. 
3. FOR hint, nodes IN evidence_by_hint.items():
4.     parts.append("=== Evidence type: %s ===" % hint)
5.     
6.     FOR n IN nodes[:8]:  // 每个hint最多8个节点
7.         parts.append(
8.             "[id=%s conf=%.2f] %s"
9.             % (n.node_id[:8], n.belief.confidence, n.evidence.content[:250])
10.         )
11.     
12.     IF nodes is empty:
13.         parts.append("(no evidence of this type)")
14. 
15. RETURN "\n".join(parts)
```

#### 3.1.5 Filled Slots解析算法

```
Algorithm: _parse_filled_slots
Input: raw (str)
Output: Dict[str, Any]

1. // 提取JSON (处理markdown代码块)
2. IF "```" IN raw:
3.     raw ← raw.split("```")[1]
4.     IF raw.startswith("json"):
5.         raw ← raw[4:]
6.     raw ← raw.strip()
7. 
8. TRY:
9.     RETURN json.loads(raw)
10. EXCEPT json.JSONDecodeError:
11.     // Fallback: 返回原始输出
12.     RETURN {
13.         "raw_output": {
14.             "value": raw,
15.             "confidence": 0.5,
16.             "source_evidence_ids": []
17.         }
18.     }
```

#### 3.1.6 可读内容生成算法

```
Algorithm: _slots_to_readable
Input: aspect (str), question (str), filled_slots (Dict[str, Any])
Output: str

1. lines ← ["## %s" % aspect, "", "**Q:** %s" % question, ""]
2. 
3. FOR slot_name, slot_data IN filled_slots.items():
4.     IF isinstance(slot_data, dict):
5.         value ← slot_data.get("value")
6.         conf ← slot_data.get("confidence", 0)
7.         
8.         IF value is not None:
9.             lines.append("**%s** (conf=%.2f):" % (slot_name, conf))
10.             lines.append(str(value))
11.             lines.append("")
12.         ELSE:
13.             lines.append("**%s**: [insufficient evidence]" % slot_name)
14.             lines.append("")
15.     ELSE:
16.         lines.append("**%s**: %s" % (slot_name, str(slot_data)))
17.         lines.append("")
18. 
19. RETURN "\n".join(lines)
```

#### 3.2.1 Filled Slot结构

```python

    "slot_name": {
        "value": str | None,              # 提取的内容, 如果证据不足则为None
        "confidence": float,              # 0.0-1.0, 提取的置信度
        "source_evidence_ids": List[str]  # 使用的证据节点ID列表
    },
    ...
}
```

#### 3.2.2 Generated Content Node结构

```python

    evidence=Evidence(
        content: str,                    # Readable content文本
        content_type: "generated_content",
        source: "content_generator",
        metadata={
            "aspect": str,
            "question": str,
            "filled_slots": Dict[str, Any],  # 完整的filled_slots JSON

### 3.3 错误处理

#### 3.3.1 Proposal JSON解析失败

**错误类型**: json.JSONDecodeError

**处理策略**:
```python
try:
    proposal = json.loads(proposal_node.evidence.content)
except json.JSONDecodeError:
    proposal = {
        "aspect": "general",
        "question": proposal_node.evidence.content,
        "slots": [{"name": "content", "description": "Main content", "evidence_hint": "any"}]
    }
```

**影响**: 使用简单proposal继续处理

#### 3.3.2 Slot提取失败

**错误类型**: Exception (LLM调用失败、超时等)

**处理策略**:
```python
try:
    gen_node = await self._extract_for_proposal(...)
    if gen_node:
        generated_nodes.append(gen_node)
except Exception as e:
    logger.error("slot_extraction_failed", proposal_aspect=..., error=str(e))
    # 跳过该proposal, 继续处理其他
```

**影响**: 跳过失败的proposal, 不影响其他proposal的处理

#### 3.3.3 Filled Slots解析失败

**错误类型**: json.JSONDecodeError

**处理策略**:
```python
try:
    return json.loads(raw)
except json.JSONDecodeError:
    return {"raw_output": {"value": raw, "confidence": 0.5, "source_evidence_ids": []}}
```

**影响**: 使用原始输出作为fallback, 继续处理

## 4. GenerationAgent详细设计

### 4.1 算法流程

#### 4.1.1 主执行算法

```
Algorithm: _execute
Input: agent_input (AgentInput)
Output: AgentOutput

1. query ← agent_input.query
2. evidence_graph ← agent_input.evidence_graph
3. 
4. logger.info("generation_pipeline_start", query=query)
5. 
6. // Stage 1: Proposal Decomposition
7. proposal_nodes ← await proposal_decomposer.generate_proposals(query, evidence_graph)
8. 
9. IF proposal_nodes is empty:
10.     RETURN AgentOutput(
11.         agent_name="generation_agent",
12.         status=AgentStatus.ERROR,
13.         error_message="No proposals generated",
14.         summary="Failed to decompose generation task into proposals."
15.     )
16. 
17. // Stage 2: Slot Extraction
18. generated_nodes ← await content_generator.generate(proposal_nodes, evidence_graph, query)
19. 
20. // Assemble final output
21. final_text ← _assemble_output(generated_nodes)
22. 
23. all_new_nodes ← proposal_nodes + generated_nodes
24. 
25. // 确定状态
26. IF generated_nodes:
27.     status ← AgentStatus.SUCCESS
28. ELSE:
29.     status ← AgentStatus.PARTIAL
30. 
31. logger.info(
32.     "generation_pipeline_complete",
33.     proposals=len(proposal_nodes),
34.     generated=len(generated_nodes),
35.     status=status.value
36. )
37. 
38. RETURN AgentOutput(
39.     agent_name="generation_agent",
40.     status=status,
41.     new_nodes=all_new_nodes,
42.     summary="Slot-filled %d sections from %d proposals." % (len(generated_nodes), len(proposal_nodes)),
43.     metrics={
44.         "proposal_count": len(proposal_nodes),
45.         "generated_count": len(generated_nodes),
46.         "final_output_length": len(final_text)
47.     }
48. )
```

#### 4.1.2 输出组装算法

```
Algorithm: _assemble_output
Input: generated_nodes (List[EvidenceNode])
Output: str

1. IF generated_nodes is empty:
2.     RETURN ""
3. 
4. sections ← []
5. FOR node IN generated_nodes:
6.     aspect ← node.evidence.metadata.get("aspect", "")
7.     content ← node.evidence.content
8.     sections.append(content)
9. 
10. RETURN "\n\n---\n\n".join(sections)
```

### 4.2 状态转换

```
初始状态: AgentStatus.PENDING
    │
    ├─▶ Proposal生成失败 → AgentStatus.ERROR
    │
    ├─▶ Proposal生成成功, 但无Generated Nodes → AgentStatus.PARTIAL
    │
    └─▶ Proposal生成成功, 且有Generated Nodes → AgentStatus.SUCCESS
```

### 4.3 错误处理

#### 4.3.1 无Proposal生成

**场景**: `proposal_nodes`为空

**处理策略**: 返回ERROR状态, error_message="No proposals generated"

**影响**: 整个Pipeline失败

#### 4.3.2 无Generated Nodes

**场景**: 所有proposal的slot提取都失败

**处理策略**: 返回PARTIAL状态

**影响**: Pipeline部分成功, 但无最终输出

## 5. 性能分析

### 5.1 时间复杂度

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| Proposal生成 | O(1) | 单次LLM调用 |
| 证据汇总 | O(E) | E为高置信度节点数 (最多15个) |
| 证据类型统计 | O(N) | N为证据图节点总数 |
| Slot提取 (单个proposal) | O(1) | 单次LLM调用 |
| Slot提取 (所有proposal) | O(P) | P为proposal数量 (最多5个) |
| 证据匹配 | O(N × S) | N为节点数, S为slot数量 |
| 总体 | O(N + P) | N为节点数, P为proposal数 |

### 5.2 空间复杂度

| 数据结构 | 空间复杂度 | 说明 |
|---------|-----------|------|
| Proposal Nodes | O(P) | P个proposal节点 |
| Generated Nodes | O(P) | P个生成节点 |
| Evidence Summary | O(E) | E个节点摘要 |
| Evidence by Hint | O(N) | 证据图节点 |
| 总体 | O(N + P) | N为节点数, P为proposal数 |

### 5.3 优化建议

1. **并行化Slot提取**: 可以并行处理多个proposal的slot提取 (未来优化)
2. **缓存证据汇总**: 如果evidence_graph未变化, 可以缓存汇总结果
3. **限制证据节点数**: 每个hint类型最多8个节点, 减少LLM输入长度

## 6. 测试用例设计

### 6.1 ProposalDecomposer测试用例

#### TC-PD-1: 正常Proposal生成

## 7. 集成点设计

### 7.1 与Retrieval Agent的集成

**输入**: EvidenceGraph (来自Retrieval Agent)

**要求**:
- EvidenceGraph必须包含至少1个节点
- 节点应包含tags信息 (用于evidence_hint匹配)
- 节点应包含confidence信息 (用于过滤)

### 7.2 与Evaluation Agent的集成

**输出**: Generated Content Nodes

**要求**:
- 每个Generated Content Node包含filled_slots元数据
- 每个filled slot包含source_evidence_ids, 便于追溯
- 每个节点包含confidence信息, 便于评估

### 7.3 与LangGraph的集成

**接口**: BaseAgent.run(state: PipelineState)

**要求**:
- 从state中提取query和evidence_graph
- 返回state更新字典 (包含updated evidence_graph和agent_outputs)

## 8. 配置参数说明

### 8.1 GENERATION_MAX_PROPOSALS

- **类型**: int
- **默认值**: 5
- **说明**: 最大proposal数量
- **影响**: 限制proposal分解的上限, 影响最终输出的section数量

### 8.2 GENERATION_PROPOSAL_TEMPERATURE

- **类型**: float
- **默认值**: 0.3
- **说明**: Proposal生成的LLM温度参数
- **影响**: 较低温度保证proposal结构的一致性

## 9. 提示词设计

### 9.1 proposal_decompose_system.md

**用途**: 指导LLM生成相同结构的proposal

**关键要求**:
- 强调所有proposal共享相同结构
- 说明proposal是slot-filling任务, 不是模板
- 限制最大proposal数量

### 9.2 slot_extraction_system.md

**用途**: 指导LLM从证据中提取信息填充slots

**关键要求**:
- 强调只能从提供的证据中提取
- 证据不足时设置value为null, confidence为0
- 禁止虚构信息
- 要求输出JSON格式, 包含source_evidence_ids

## 10. 监控指标

### 10.1 关键指标

| 指标 | 说明 | 目标值 |
|------|------|--------|
| proposal_count | Proposal生成数量 | 1-5 |
| generated_count | 成功生成的内容数量 | 1-5 |
| filled_count / slot_count | Slot填充率 | > 0.5 |
| avg_confidence | 平均置信度 | > 0.7 |
| elapsed_seconds | 总耗时 | < 90秒 |

### 10.2 告警阈值

- proposal_count = 0: ERROR告警
- generated_count = 0: WARNING告警
- filled_count / slot_count < 0.3: WARNING告警
- elapsed_seconds > 120: WARNING告警
