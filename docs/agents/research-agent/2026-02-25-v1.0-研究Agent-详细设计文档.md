## 2. DomainScout详细设计

### 2.1 算法流程

#### 2.1.1 主流程算法

```
Algorithm: scout
Input: research_topic (str)
Output: Dict[str, Any] — {domain_context, journal_entry}

1. logger.info("domain_scout_start", topic=research_topic)
2. web_results ← await _search_web(research_topic)
3. domain_context ← await _analyze_with_llm(research_topic, web_results)
4. journal ← JournalEntry(phase="scout", summary=..., details=...)
5. RETURN {"domain_context": domain_context, "journal_entry": journal}
```

#### 2.1.2 Web搜索算法

```
Algorithm: _search_web
Input: topic (str)
Output: List[Dict[str, Any]]

1. IF brave_client not enabled:
2.     RETURN []
3.
4. queries ← [
5.     topic,
6.     "{topic} survey 2025 2026",
7.     "{topic} state of the art recent advances"
8. ]
9.
10. all_results ← []
11. FOR q IN queries:
12.     results ← await brave_client.web_search(q, count=5)
13.     all_results.extend(results)
14.
15. // URL级去重
16. seen_urls ← set()
17. deduped ← []
18. FOR r IN all_results:
19.     url ← r.get("url", "")
20.     IF url AND url NOT IN seen_urls:
21.         seen_urls.add(url)
22.         deduped.append(r)
23.
24. RETURN deduped[:15]
```

#### 2.1.3 LLM分析算法

```
Algorithm: _analyze_with_llm
Input: topic (str), web_results (List[Dict])
Output: Dict[str, Any]

1. system_prompt ← load_prompt("research_scout_system", research_topic=topic)
2.
3. results_text ← 格式化web_results为markdown列表
4. user_content ← "Research topic: {topic}\n\nWeb search results:\n{results_text}\n\nAnalyze..."
5.
6. messages ← [SystemMessage(system_prompt), HumanMessage(user_content)]
7.
8. TRY:
9.     response ← await llm_service.call(messages, prompt_name="research_scout_system")
10.    RETURN _parse_json_response(response.content)
11. EXCEPT Exception:
12.    RETURN fallback: {keywords: [], directions: [], refined_queries: [topic]}
```

### 2.2 输出数据结构

```python
domain_context = {
    "keywords": List[str],             # 10-20个领域关键词
    "directions": [                    # 3-5个研究方向
        {
            "name": str,
            "description": str,
            "relevance": float         # 0.0-1.0
        }
    ],
    "core_problems": List[str],        # 未解决的核心问题
    "refined_queries": List[str],      # 3-5个精炼查询 (供Survey使用)
    "summary": str                     # 2-3段领域概述
}
```

## 3. LiteratureSurveyor详细设计

### 3.1 算法流程

#### 3.1.1 主流程算法

```
Algorithm: survey
Input: research_topic (str), domain_context (dict), iteration (int)
Output: Dict[str, Any] — {papers, survey_assessment, journal_entry}

1. queries ← domain_context.get("refined_queries", [research_topic])
2. raw_papers ← await _retrieve_papers(queries)
3. papers ← _deduplicate(raw_papers)
4. assessment ← await _assess_papers(research_topic, papers, iteration)
5. _apply_relevance_scores(papers, assessment)
6. papers.sort(key=relevance_score, reverse=True)
7. RETURN {papers, assessment, journal}
```

#### 3.1.2 多源检索算法

```
Algorithm: _retrieve_papers
Input: queries (List[str])
Output: List[Paper]

1. all_papers ← []
2. FOR query IN queries[:5]:                  // 最多5个查询
3.     arxiv_results ← await arxiv_client.search(query)
4.     FOR r IN arxiv_results:
5.         all_papers.append(Paper(
6.             title=r.title, authors=r.authors, abstract=r.abstract,
7.             year=r.year, url=r.url, arxiv_id=r.arxiv_id,
8.             source=PaperSource.ARXIV
9.         ))
10.
11.    s2_results ← await s2_client.search(query)
12.    FOR r IN s2_results:
13.        all_papers.append(Paper(
14.            title=r.title, authors=r.authors, abstract=r.abstract,
15.            year=r.year, url=r.url, doi=r.doi,
16.            citation_count=r.citation_count,
17.            source=PaperSource.SEMANTIC_SCHOLAR
18.        ))
19.
20. RETURN all_papers
```

#### 3.1.3 去重算法

```
Algorithm: _deduplicate
Input: papers (List[Paper])
Output: List[Paper]

1. seen ← set()
2. unique ← []
3. FOR p IN papers:
4.     key ← p.dedup_key()         // DOI > arXiv ID > title(lower)
5.     IF key NOT IN seen:
6.         seen.add(key)
7.         unique.append(p)
8. RETURN unique
```

#### 3.1.4 相关性评估算法

```
Algorithm: _assess_papers
Input: research_topic (str), papers (List[Paper]), iteration (int)
Output: Dict[str, Any]

1. system_prompt ← load_prompt("research_survey_system", ...)
2. papers_text ← 格式化Top 30论文 (标题 + 作者 + 年份 + 摘要前300字)
3. messages ← [SystemMessage, HumanMessage(papers_text)]
4.
5. TRY:
6.     response ← await llm_service.call(messages)
7.     RETURN _parse_json_response(response.content)
8. EXCEPT:
9.     RETURN {paper_assessments: [], common_themes: [], gaps: []}
```

### 3.2 Paper去重Key优先级

| 优先级 | 条件 | 格式 |
|--------|------|------|
| 1 (最高) | paper.doi存在 | `"doi:{doi}"` |
| 2 | paper.arxiv_id存在 | `"arxiv:{arxiv_id}"` |
| 3 (最低) | fallback | `"title:{title.lower().strip()}"` |

## 4. KnowledgeSynthesizer详细设计

### 4.1 算法流程

```
Algorithm: synthesize
Input: research_topic, domain_context, papers, survey_assessment, iteration, previous_findings
Output: Dict[str, Any] — {synthesis_report, hypotheses, journal_entry}

1. gaps ← survey_assessment.get("gaps", [])
2.
3. system_prompt ← load_prompt("research_synthesize_system",
4.     research_topic=research_topic,
5.     domain_context=json.dumps(domain_context)[:1000],
6.     gaps=json.dumps(gaps),
7.     iteration=iteration,
8.     previous_findings=previous_findings or ""
9. )
10.
11. papers_text ← 格式化Top 20论文 (按relevance_score降序)
12. themes_text ← 格式化common_themes列表
13.
14. messages ← [SystemMessage, HumanMessage(papers_text + themes + gaps)]
15.
16. TRY:
17.    response ← await llm_service.call(messages)
18.    result ← _parse_json_response(response.content)
19. EXCEPT:
20.    result ← {synthesis: "failed", hypotheses: []}
21.
22. hypotheses ← _build_hypotheses(result.get("hypotheses", []))
23. RETURN {synthesis_report, hypotheses, journal}
```

### 4.2 Hypothesis构建逻辑

```
Algorithm: _build_hypotheses
Input: raw_hypotheses (List[Dict])
Output: List[Hypothesis]

FOR h IN raw_hypotheses[:5]:
    confidence ← min(testability * impact, 1.0)
    hypotheses.append(Hypothesis(
        statement=h.statement,
        rationale=h.rationale,
        supporting_papers=h.supporting_papers,
        confidence=confidence,
        status=HypothesisStatus.PROPOSED
    ))
```

### 4.3 Hypothesis数据结构

```python
Hypothesis(
    hypothesis_id: str,              # UUID
    statement: str,                  # 假设陈述
    rationale: str,                  # 提出理由
    supporting_papers: List[str],    # 支撑论文标题/ID
    status: HypothesisStatus,       # proposed → testing → confirmed/rejected/inconclusive
    confidence: float,               # 0.0-1.0
    test_results: List[str],         # 关联的experiment_id列表
    created_at: datetime
)
```

## 5. ExperimentDesigner详细设计

### 5.1 算法流程

```
Algorithm: design
Input: hypothesis (Hypothesis), research_topic (str), previous_results (str), iteration (int)
Output: Dict[str, Any] — {experiment, journal_entry}

1. system_prompt ← load_prompt("research_design_system",
2.     hypothesis=hypothesis.statement,
3.     research_topic=research_topic,
4.     previous_results=previous_results or "None",
5.     iteration=iteration
6. )
7.
8. user_content ← 格式化hypothesis + rationale
9. messages ← [SystemMessage, HumanMessage(user_content)]
10.
11. TRY:
12.    response ← await llm_service.call(messages)
13.    result ← _parse_json_response(response.content)
14. EXCEPT:
15.    result ← {}
16.
17. experiment ← _build_experiment(result, hypothesis, iteration)
18. RETURN {experiment, journal}
```

### 5.2 Experiment数据结构

```python
Experiment(
    experiment_id: str,          # UUID
    name: str,                   # 实验名称 (LLM生成)
    description: str,            # 实验描述
    hypothesis_id: str | None,   # 关联假设ID
    code: str,                   # 完整Python代码
    dependencies: List[str],     # pip包列表 (e.g. ["numpy", "scikit-learn"])
    expected_metrics: List[str], # 预期指标名称
    success_criteria: str,       # 成功判定标准
    status: ExperimentStatus,    # designed → running → completed/failed/timeout
    result: ExperimentResult | None,
    iteration: int,              # 所属迭代轮次
    created_at: datetime
)
```

### 5.3 代码生成约束

LLM生成的实验代码必须满足:
- 单文件, `python experiment.py` 可执行
- 结果以JSON格式打印到stdout
- 处理自身异常, 在JSON中报告错误
- 5分钟内完成
- 不依赖GPU或大数据集

## 6. ExperimentRunner详细设计

### 6.1 算法流程

```
Algorithm: run
Input: experiment (Experiment)
Output: Dict[str, Any] — {experiment (with result), journal_entry}

1. experiment.status ← RUNNING
2. result ← await sandbox.execute(code=experiment.code, dependencies=experiment.dependencies)
3.
4. IF result.exit_code == 124:
5.     experiment.status ← TIMEOUT
6. ELIF result.exit_code != 0:
7.     experiment.status ← FAILED
8. ELSE:
9.     experiment.status ← COMPLETED
10.
11. experiment.result ← result
12. RETURN {experiment, journal}
```

### 6.2 SandboxEngine执行流程

```
Algorithm: execute
Input: code (str), dependencies (List[str]), env_vars (Dict[str, str])
Output: ExperimentResult

1. IF code is empty:
2.     RETURN ExperimentResult(exit_code=1, stderr="empty code")
3.
4. docker_available ← await _check_docker()
5.
6. IF docker_available:
7.     RETURN await _execute_docker(code, dependencies, env_vars)
8. ELSE:
9.     RETURN await _execute_subprocess(code, dependencies)
```

#### Docker执行

```
Algorithm: _execute_docker
1. tmpdir ← tempfile.mkdtemp()
2. write experiment.py to tmpdir
3. write setup.sh (pip install dependencies) to tmpdir
4. cmd ← ["docker", "run", "--rm",
5.     "--memory=2g", "--cpus=1", "--network=none",
6.     "-v", "{tmpdir}:/workspace:rw", "-w", "/workspace",
7.     "python:3.11-slim",
8.     "bash", "-c", "bash /workspace/setup.sh && python /workspace/experiment.py"]
9. RETURN await _run_process(cmd)
```

#### 进程执行与超时

```
Algorithm: _run_process
Input: cmd (List[str])
Output: ExperimentResult

1. start ← time.monotonic()
2. TRY:
3.     proc ← asyncio.create_subprocess_exec(*cmd, stdout=PIPE, stderr=PIPE)
4.     stdout, stderr ← await asyncio.wait_for(proc.communicate(), timeout=self.timeout)
5.     elapsed ← time.monotonic() - start
6.     metrics ← _try_parse_metrics(stdout)    // 解析最后一行JSON
7.     RETURN ExperimentResult(stdout, stderr, exit_code, metrics, elapsed)
8. EXCEPT TimeoutError:
9.     proc.kill()
10.    RETURN ExperimentResult(exit_code=124, stderr="timed out")
```

### 6.3 ExperimentResult数据结构

```python
ExperimentResult(
    stdout: str,                 # 截断到10000字符
    stderr: str,                 # 截断到5000字符
    exit_code: int,              # 0=成功, 124=超时, 其他=失败
    output_files: Dict[str, str],# 预留
    metrics: Dict[str, Any],     # 从stdout最后一行JSON解析
    elapsed_seconds: float
)
```

## 7. ResultAnalyzer详细设计

### 7.1 算法流程

```
Algorithm: analyze
Input: experiment (Experiment), hypothesis (Hypothesis), iteration (int)
Output: Dict[str, Any] — {analysis_report, hypothesis_update, improvement_suggestions, journal_entry}

1. IF experiment.result is None:
2.     RETURN _empty_analysis(experiment, hypothesis)
3.
4. system_prompt ← load_prompt("research_analyze_system",
5.     hypothesis=hypothesis.statement,
6.     experiment_name=experiment.name,
7.     exit_code=experiment.result.exit_code,
8.     stdout=experiment.result.stdout[:3000],
9.     stderr=experiment.result.stderr[:1000],
10.    iteration=iteration
11. )
12.
13. user_content ← 格式化 hypothesis + success_criteria + metrics
14. messages ← [SystemMessage, HumanMessage]
15.
16. TRY:
17.    response ← await llm_service.call(messages)
18.    result ← _parse_json_response(response.content)
19. EXCEPT:
20.    result ← {hypothesis_status: "inconclusive", confidence: 0.3}
21.
22. // 更新假设状态
23. status_map ← {confirmed: CONFIRMED, rejected: REJECTED, inconclusive: INCONCLUSIVE}
24. hypothesis.status ← status_map.get(result.hypothesis_status, INCONCLUSIVE)
25. hypothesis.confidence ← result.confidence
26. hypothesis.test_results.append(experiment.experiment_id)
27.
28. RETURN {analysis_report, hypothesis_update: hypothesis, improvement_suggestions, journal}
```

### 7.2 假设状态转换

```
PROPOSED ──(design)──▶ TESTING ──(analyze)──▶ CONFIRMED
                                           ──▶ REJECTED
                                           ──▶ INCONCLUSIVE
```

## 8. IterationPlanner详细设计

### 8.1 算法流程

```
Algorithm: decide
Input: research_topic, hypotheses, analysis_report, iteration, max_iterations, iteration_history
Output: Dict[str, Any] — {decision, iteration_record, journal_entry, final_report}

1. // 硬限制: 达到max_iterations强制conclude
2. IF iteration >= max_iterations:
3.     RETURN _force_conclude(...)
4.
5. hypotheses_summary ← _summarize_hypotheses(hypotheses)
6. history_summary ← _summarize_history(iteration_history)
7.
8. system_prompt ← load_prompt("research_decide_system", ...)
9. messages ← [SystemMessage, HumanMessage("Based on context, what next?")]
10.
11. TRY:
12.    response ← await llm_service.call(messages)
13.    result ← _parse_json_response(response.content)
14. EXCEPT:
15.    result ← {decision: "conclude"}
16.
17. decision ← map(result.decision → ResearchDecision)
18. iteration_record ← IterationRecord(iteration, decision, direction, key_findings, ...)
19.
20. IF decision == CONCLUDE:
21.    final_report ← result.report_summary
22. ELIF decision == ITERATE:
23.    // 更新domain_context.refined_queries, 推入新方向
24.
25. RETURN {decision, iteration_record, journal, final_report}
```

### 8.2 决策收敛策略

| 条件 | 偏向决策 | 理由 |
|------|---------|------|
| iteration >= max_iterations | 强制conclude | 硬限制 |
| 迭代改进 < 5% 且 iterations >= 2 | conclude | 收益递减 |
| 所有hypothesis rejected, 无新方向 | pivot 或 conclude | 方向不对 |
| 有明确未探索角度 | iterate | 还有改进空间 |
| LLM分析失败 | conclude | 安全退出 |

### 8.3 IterationRecord数据结构

```python
IterationRecord(
    iteration: int,                  # 迭代轮次 (1-indexed)
    decision: ResearchDecision,      # iterate / pivot / conclude
    direction: str,                  # 下一步方向 (conclude时为空)
    key_findings: List[str],         # 本轮关键发现
    hypotheses_tested: int,
    hypotheses_confirmed: int,
    experiments_run: int,
    created_at: datetime
)
```

## 9. ResearchGateway详细设计

### 9.1 路由算法

```
Algorithm: research_gateway
Input: state (ResearchState)
Output: Command[RESEARCH_ROUTE_TARGETS]

1. phase ← state.current_phase
2. iteration ← state.iteration_count
3.
4. // 安全: 超过max_iterations强制conclude
5. IF iteration > state.max_iterations:
6.     RETURN Command(update={current_phase: "conclude"}, goto="conclude")
7.
8. // Phase-based直接路由
9. MATCH phase:
10.    "scout" → goto "scout"
11.    "survey" → goto "survey"
12.    "synthesize" → goto "synthesize"
13.    "design" → goto "design"
14.    "experiment" → goto "experiment"
15.    "analyze" → goto "analyze"
16.    "decide" → goto "decide"
17.    "conclude" → goto "conclude"
18.    default → update current_phase="scout", goto "scout"
```

### 9.2 post_decide路由算法

```
Algorithm: research_post_decide
Input: state (ResearchState)
Output: Dict — {current_phase: str}

1. latest ← state.iteration_history[-1]
2.
3. MATCH latest.decision:
4.    ITERATE → current_phase = "survey"
5.    PIVOT → current_phase = "scout"
6.    CONCLUDE → current_phase = "conclude"
```

## 11. 性能分析

### 11.1 时间复杂度

| 操作 | 时间 | 说明 |
|------|------|------|
| Scout (Brave搜索) | 3-10s | 3个查询 * Brave API延迟 |
| Scout (LLM分析) | 5-15s | 单次LLM调用 |
| Survey (arXiv检索) | 5-15s | 每个query 3-5s, 最多5个query |
| Survey (S2检索) | 5-15s | 每个query 3-5s, 最多5个query |
| Survey (LLM评估) | 5-15s | 单次LLM调用 |
| Synthesize | 10-20s | 单次LLM调用 (长上下文) |
| Design | 10-20s | 单次LLM调用 (代码生成) |
| Experiment | 10-300s | 取决于实验代码 |
| Analyze | 5-15s | 单次LLM调用 |
| Decide | 5-10s | 单次LLM调用 |
| **单次迭代总计** | **60-400s** | |
| **5次迭代** | **5-30min** | |

### 11.2 LLM调用次数

| 阶段 | 调用次数/迭代 | 说明 |
|------|-------------|------|
| Scout | 1 | 仅首次迭代 (pivot时再次) |
| Survey | 1 | 论文评估 |
| Synthesize | 1 | 知识综合 |
| Design | 1 | 实验设计 |
| Analyze | 1 | 结果分析 |
| Decide | 1 | 迭代决策 |
| **总计/迭代** | **5-6** | |
| **5次迭代** | **25-30** | |

| TC-RA-3 | 实验失败 | failed实验 | hypothesis.status=INCONCLUSIVE |
| TC-RA-4 | 无结果 | experiment.result=None | hypothesis.status=INCONCLUSIVE |

## 13. 术语表

| 术语 | 英文 | 定义 |
|------|------|------|
| 研究闭环 | Research Loop | 完整的研究循环: 探索→检索→综合→实验→分析→决策 |
| 领域上下文 | Domain Context | 领域探索产出的结构化知识 (关键词, 方向, 问题) |

| 实验 | Experiment | 含可执行代码和评价指标的测试方案 |
| 沙箱 | Sandbox | 隔离的代码执行环境 (Docker/subprocess) |
| 迭代决策 | Iteration Decision | iterate(继续)/pivot(转向)/conclude(结束) |
| 研究日志 | Research Journal | 按时间排序的阶段执行日志 |
| 迭代记录 | Iteration Record | 每轮迭代的决策和关键发现摘要 |
| 去重Key | Dedup Key | 论文去重标识 (DOI > arXiv ID > 标题) |
| Reducer | Reducer | LangGraph状态合并策略函数 |
