## 2. QueryClassifier详细设计

### 2.1 算法描述

QueryClassifier使用LLM将用户查询分类为8种QDMR类型之一, 并为每种类型配置检索策略.

### 2.2 核心算法

```python
async def classify(query: str, evidence_graph: EvidenceGraph) -> (ClassificationResult, EvidenceNode):
    """
    查询分类算法
    
    输入:
        query: 用户查询字符串
        evidence_graph: 证据图
    
    输出:
        ClassificationResult: 分类结果
        EvidenceNode: 分类证据节点
    """
    try:
        # 1. 构建LLM提示
        system_prompt = load_prompt("query_classify_system", max_depth=self.max_depth)
        messages = [
            SystemMessage(content=system_prompt),
            HumanMessage(content=f"Classify this query:\n{query}")
        ]
        
        # 2. 调用LLM
        response = await llm_service.call(messages, prompt_name="query_classify_system")
        content = response.content.strip()
        
        # 3. 解析JSON响应
        if "```" in content:
            content = extract_json_from_markdown(content)
        
        data = json.loads(content)
        
        # 4. 映射到QType枚举
        q_type_str = data.get("q_type", "QSelect")
        try:
            q_type = QType(q_type_str)
        except ValueError:
            logger.warning("unknown_q_type", raw=q_type_str)
            q_type = QType.Q_SELECT  # 默认类型
        
        # 5. 提取分类信息
        confidence = clamp(float(data.get("confidence", 0.7)), 0.0, 1.0)
        reasoning = data.get("reasoning", "")
        hints = data.get("decomposition_hint", [])
        if isinstance(hints, str):
            hints = [hints]
        
        # 6. 获取策略配置
        strategy = StrategyConfig.for_type(q_type, self.backtrack_threshold)
        
        # 7. 创建分类结果
        result = ClassificationResult(
            q_type=q_type,
            confidence=confidence,
            reasoning=reasoning,
            decomposition_hint=hints,
            strategy=strategy
        )
        
        # 8. 创建证据节点
        node = evidence_graph.add_evidence(...)
        
        return result, node
        
    except Exception as e:
        logger.error("query_classification_failed", error=str(e))
        # 降级策略: 默认使用QComposition
        q_type = QType.Q_COMPOSITION
        strategy = StrategyConfig.for_type(q_type, self.backtrack_threshold)
        return ClassificationResult(
            q_type=q_type,
            confidence=0.5,
            reasoning=f"Classification failed ({e}), defaulting to QComposition",
            decomposition_hint=[],
            strategy=strategy
        ), create_fallback_node(...)
```

### 2.3 错误处理

1. **LLM调用失败**: 返回默认QComposition类型, 置信度0.5
2. **JSON解析失败**: 尝试提取JSON, 如果失败则使用默认类型
3. **未知QType**: 记录警告日志, 使用QSelect作为默认类型

### 2.4 策略配置映射

```python
@staticmethod
def for_type(q_type: QType, backtrack_threshold: float = 0.4) -> StrategyConfig:
    """根据QType获取策略配置"""
    configs = {
        QType.Q_SELECT: StrategyConfig("rag", "kg", 2, backtrack_threshold),
        QType.Q_FILTER: StrategyConfig("rag", "kg", 2, backtrack_threshold),
        QType.Q_CHAIN: StrategyConfig("kg", "rag", 3, backtrack_threshold),
        QType.Q_COMPOSITION: StrategyConfig("both", "both", 3, backtrack_threshold),
        QType.Q_COMPARISON: StrategyConfig("both", "both", 3, backtrack_threshold),
        QType.Q_AGGREGATION: StrategyConfig("kg", "rag", 2, backtrack_threshold),
        QType.Q_BOOLEAN: StrategyConfig("rag", "kg", 1, backtrack_threshold),
        QType.Q_UNION: StrategyConfig("both", "both", 3, backtrack_threshold),
    }
    return configs.get(q_type, StrategyConfig("both", "both", 2, backtrack_threshold))
```

## 3. QueryDecomposer详细设计

### 3.1 QDMR分解算法

```python
async def qdmr_decompose(
    query: str,
    q_type: QType,
    max_steps: int = 5
) -> List[TreeStep]:
    """
    QDMR感知分解算法
    
    输入:
        query: 原始查询
        q_type: 查询类型
        max_steps: 最大步骤数
    
    输出:
        List[TreeStep]: 树形步骤列表
    """
    try:
        # 1. 调用LLM进行QDMR分解
        raw_steps = await self._llm_qdmr_decompose(query, q_type, max_steps)
    except Exception as e:
        logger.error("qdmr_decomposition_failed", error=str(e))
        # 降级策略: 使用原始查询作为单一步骤
        raw_steps = [{
            "step": 1,
            "question": query,
            "operator": "select",
            "retrieval_strategy": "both",
            "depends_on": []
        }]
    
    # 2. 转换为TreeStep对象
    steps = []
    for raw in raw_steps:
        steps.append(TreeStep(
            step_idx=int(raw.get("step", len(steps) + 1)),
            question=raw.get("question", query),
            operator=raw.get("operator", "select"),
            retrieval_strategy=raw.get("retrieval_strategy", "both"),
            depends_on=raw.get("depends_on", [])
        ))
    
    return steps
```

### 3.2 LLM QDMR分解

```python
async def _llm_qdmr_decompose(
    query: str,
    q_type: QType,
    max_steps: int
) -> List[Dict[str, Any]]:
    """使用LLM进行QDMR分解"""
    # 1. 构建提示
    messages = [
        SystemMessage(content=load_prompt(
            "qdmr_decompose_system",
            q_type=q_type.value,
            max_steps=max_steps
        )),
        HumanMessage(content=f"Decompose this query (type: {q_type.value}):\n{query}")
    ]
    
    # 2. 调用LLM
    response = await llm_service.call(messages, prompt_name="qdmr_decompose_system")
    content = response.content.strip()
    
    # 3. 解析JSON
    if "```" in content:
        content = extract_json_from_markdown(content)
    
    parsed = json.loads(content)
    
    # 4. 规范化输出格式
    if isinstance(parsed, list):
        return parsed[:max_steps]
    if isinstance(parsed, dict):
        return [parsed]
    
    # 降级: 返回单一步骤
    return [{
        "step": 1,
        "question": query,
        "operator": "select",
        "retrieval_strategy": "both",
        "depends_on": []
    }]
```

### 3.3 经典分解算法

```python
async def decompose(
    query: str,
    evidence_graph: EvidenceGraph
) -> List[EvidenceNode]:
    """
    经典分解算法(平面子查询分解)
    
    输入:
        query: 原始查询
        evidence_graph: 证据图
    
    输出:
        List[EvidenceNode]: 子查询节点列表
    """
    # 1. 创建根查询节点
    root_node = create_root_query_node(query, evidence_graph)
    
    # 2. LLM分解
    try:
        sub_queries = await self._llm_decompose(query)
    except Exception as e:
        logger.error("query_decomposition_failed", error=str(e))
        sub_queries = [{"query": query, "aspect": "original"}]
    
    # 3. 创建子查询节点
    sub_query_nodes = []
    for i, sq in enumerate(sub_queries):
        sq_text = sq.get("query", query)
        aspect = sq.get("aspect", f"aspect_{i}")
        
        node = evidence_graph.add_evidence(
            evidence=Evidence(
                content=sq_text,
                content_type="sub_query",
                source="query_decomposer",
                metadata={"aspect": aspect, "index": i}
            ),
            belief=Belief(...),
            intent=Intent(...),
            parent_node_ids=[root_node.node_id],
            relation=EdgeRelation.DECOMPOSES_TO,
            tags=["sub_query", aspect]
        )
        sub_query_nodes.append(node)
    
    return [root_node] + sub_query_nodes
```

## 4. TreeExplorer详细设计

### 4.1 树形探索算法

```python
async def explore(
    steps: List[TreeStep],
    classification: ClassificationResult,
    evidence_graph: EvidenceGraph,
    parent_node: EvidenceNode
) -> List[EvidenceNode]:
    """
    树形探索算法(带回溯)
    
    输入:
        steps: QDMR分解步骤列表
        classification: 查询分类结果
        evidence_graph: 证据图
        parent_node: 父节点(分类节点)
    
    输出:
        List[EvidenceNode]: 所有检索结果节点
    """
    all_nodes = []
    step_results = {}
    
    for step in steps:
        logger.info("tree_step_start", step=step.step_idx, question=step.question[:80])
        
        # 1. 创建步骤节点
        step_node = evidence_graph.add_evidence(...)
        all_nodes.append(step_node)
        
        # 2. 确定检索策略
        primary = self._resolve_strategy(
            step.retrieval_strategy,
            classification.strategy.primary_strategy
        )
        fallback = self._resolve_strategy(
            step.retrieval_strategy,
            classification.strategy.fallback_strategy
        )
        
        # 3. 执行主要策略
        branch_nodes = await self._execute_branch(
            step, step_node, evidence_graph, primary
        )
        quality = self._evaluate_quality(branch_nodes)
        
        logger.info("tree_branch_result", step=step.step_idx, strategy=primary, quality=quality)
        
        # 4. 回溯判断
        if quality < self.backtrack_threshold and fallback != primary:
            logger.info("tree_backtrack", step=step.step_idx, from_strategy=primary, to_strategy=fallback)
            step.backtracked = True
            
            # 5. 执行备选策略
            fallback_nodes = await self._execute_branch(
                step, step_node, evidence_graph, fallback
            )
            fallback_quality = self._evaluate_quality(fallback_nodes)
            
            logger.info("tree_fallback_result", step=step.step_idx, strategy=fallback, quality=fallback_quality)
            
            # 6. 保留最佳分支
            if fallback_quality > quality:
                branch_nodes = fallback_nodes
                quality = fallback_quality
            else:
                # 保留两者(原始分支也有结果)
                branch_nodes = branch_nodes + fallback_nodes
        
        # 7. 更新步骤状态
        step.results = branch_nodes
        step.quality = quality
        step.explored = True
        step_results[step.step_idx] = branch_nodes
        all_nodes.extend(branch_nodes)
        
        logger.info("tree_step_complete", step=step.step_idx, total_nodes=len(branch_nodes), quality=quality)
    
    return all_nodes
```

### 4.2 分支执行算法

```python
async def _execute_branch(
    step: TreeStep,
    step_node: EvidenceNode,
    evidence_graph: EvidenceGraph,
    strategy: str
) -> List[EvidenceNode]:
    """
    执行单个检索分支
    
    输入:
        step: QDMR步骤
        step_node: 步骤节点
        evidence_graph: 证据图
        strategy: 检索策略("rag", "kg", "both")
    
    输出:
        List[EvidenceNode]: 检索结果节点
    """
    nodes = []
    
    # 向量检索分支
    if strategy in ("rag", "both"):
        try:
            rag_nodes = await self.vector_retriever.retrieve(
                [step_node], evidence_graph
            )
            nodes.extend(rag_nodes)
        except Exception as e:
            logger.error("vector_retrieval_failed_in_branch", step=step.step_idx, error=str(e))
            # 继续执行KG检索
    
    # 知识图谱检索分支
    if strategy in ("kg", "both"):
        try:
            kg_nodes = await self.kg_retriever.retrieve(
                [step_node], evidence_graph
            )
            nodes.extend(kg_nodes)
        except Exception as e:
            logger.error("kg_retrieval_failed_in_branch", step=step.step_idx, error=str(e))
            # 继续使用已有结果
    
    return nodes
```

### 4.3 质量评估算法

```python
@staticmethod
def _evaluate_quality(nodes: List[EvidenceNode]) -> float:
    """
    评估分支质量
    
    质量 = 平均置信度
    
    输入:
        nodes: 证据节点列表
    
    输出:
        float: 质量分数(0.0-1.0)
    """
    if not nodes:
        return 0.0
    
    total_conf = sum(n.belief.confidence for n in nodes)
    return total_conf / len(nodes)
```

### 4.4 策略解析算法

```python
@staticmethod
def _resolve_strategy(step_strategy: str, type_strategy: str) -> str:
    """
    解析检索策略
    
    如果步骤有特定策略, 使用步骤策略;
    否则使用类型级策略.
    
    输入:
        step_strategy: 步骤级策略
        type_strategy: 类型级策略
    
    输出:
        str: 最终策略("rag", "kg", "both")
    """
    if step_strategy in ("rag", "kg"):
        return step_strategy
    # "both" 或未知 -> 使用类型级策略
    return type_strategy
```

## 5. VectorRetriever详细设计

### 5.1 向量检索算法

```python
async def retrieve(
    sub_query_nodes: List[EvidenceNode],
    evidence_graph: EvidenceGraph
) -> List[EvidenceNode]:
    """
    向量检索算法
    
    输入:
        sub_query_nodes: 子查询节点列表
        evidence_graph: 证据图
    
    输出:
        List[EvidenceNode]: 文档块节点列表
    """
    all_vector_nodes = []
    
    for sq_node in sub_query_nodes:
        if sq_node.evidence.content_type != "sub_query":
            continue
        
        query_text = sq_node.evidence.content
        try:
            nodes = await self._retrieve_for_query(
                query_text, sq_node, evidence_graph
            )
            all_vector_nodes.extend(nodes)
        except Exception as e:
            logger.error("vector_retrieval_failed", query=query_text, error=str(e))
            # 跳过此查询, 继续处理其他查询
    
    logger.info("vector_retrieval_complete", total_chunks=len(all_vector_nodes))
    return all_vector_nodes
```

### 5.2 单查询检索算法

```python
async def _retrieve_for_query(
    query: str,
    parent_node: EvidenceNode,
    evidence_graph: EvidenceGraph
) -> List[EvidenceNode]:
    """
    对单个查询执行向量检索
    
    输入:
        query: 查询文本
        parent_node: 父节点
        evidence_graph: 证据图
    
    输出:
        List[EvidenceNode]: 文档块节点列表
    """
    # 1. 生成查询向量
    query_embedding = await self._embeddings.aembed_query(query)
    
    # 2. 向量相似度搜索
    results = await vector_store.similarity_search(
        query_embedding=query_embedding,
        top_k=self.top_k,
        score_threshold=self.score_threshold
    )
    
    if not results:
        return []
    
    # 3. 转换为证据节点
    nodes = []
    for i, result in enumerate(results):
        score = result.get("score", 0.0)
        
        node = evidence_graph.add_evidence(
            evidence=Evidence(
                content=result.get("content", ""),
                content_type="document_chunk",
                source=result.get("id", ""),
                metadata={
                    "similarity_score": score,
                    "doc_metadata": result.get("metadata", {}),
                    "rank": i
                }
            ),
            belief=Belief(
                content=f"Vector search result (score={score:.3f}): {result.get('content', '')[:80]}...",
                confidence=score,
                source_agent="retrieval_agent"
            ),
            intent=Intent(...),
            parent_node_ids=[parent_node.node_id],
            relation=EdgeRelation.DERIVED_FROM,
            tags=["vector_result", f"rank_{i}"]
        )
        nodes.append(node)
    
    return nodes
```

### 5.3 错误处理

1. **Embedding生成失败**: 记录错误, 跳过此查询
2. **向量搜索失败**: 记录错误, 返回空列表
3. **结果解析失败**: 使用默认值, 继续处理

## 6. KGRetriever详细设计

### 6.1 KG检索算法

```python
async def retrieve(
    sub_query_nodes: List[EvidenceNode],
    evidence_graph: EvidenceGraph
) -> List[EvidenceNode]:
    """
    KG检索算法
    
    输入:
        sub_query_nodes: 子查询节点列表

    logger.info("kg_retrieval_complete", total_chains=len(all_kg_nodes))
    return all_kg_nodes
```

### 6.2 搜索和扩展算法

```python
async def _search_and_expand(
    query: str,
    parent_node: EvidenceNode,
    evidence_graph: EvidenceGraph
) -> List[EvidenceNode]:
    """
    搜索KG并扩展
    
    步骤:
    1. 全文搜索匹配KG节点
    2. BFS扩展获取关系上下文
    3. 构建推理链
    
    输入:
        query: 查询文本
        parent_node: 父节点
        evidence_graph: 证据图
    
    输出:
        List[EvidenceNode]: KG节点列表
    """
    result_nodes = []
    
    # 步骤1: 全文搜索匹配节点
    matched_nodes = await neo4j_client.find_entities(
        text=query, limit=self.search_limit
    )
    
    if not matched_nodes:
        logger.debug("kg_no_matches", query=query)
        return []
    
    # 创建直接匹配节点
    for i, match in enumerate(matched_nodes):
        node_name = match.get("name", match.get("id", "unknown"))
        node_props = match.get("properties", {})
        node_labels = match.get("labels", [])
        
        # 构建可读描述
        content_parts = [f"[{':'.join(node_labels)}] {node_name}"]
        if node_props.get("description"):
            content_parts.append(node_props["description"])
        for k, v in node_props.items():
            if k not in ("id", "name", "description") and v:
                content_parts.append(f"  {k}: {v}")
        
        content = "\n".join(content_parts)
        
        node = evidence_graph.add_evidence(
            evidence=Evidence(
                content=content,
                content_type="kg_match",
                source="knowledge_graph",
                metadata={
                    "kg_node_id": match.get("id", ""),
                    "kg_labels": node_labels,
                    "rank": i
                }
            ),
            belief=Belief(
                content=f"KG direct match: {node_name}",
                confidence=max(0.6, 0.9 - i * 0.05),  # 按排名衰减
                source_agent="retrieval_agent"
            ),
            intent=Intent(...),
            parent_node_ids=[parent_node.node_id],
            relation=EdgeRelation.DERIVED_FROM,
            tags=["kg_match", f"rank_{i}"]
        )
        result_nodes.append(node)
    
    # 步骤2: BFS扩展
    matched_ids = [m.get("id") for m in matched_nodes if m.get("id")]
    if matched_ids:
        expansion_nodes = await self._bfs_expand(
            seed_ids=matched_ids,
            parent_node=parent_node,
            evidence_graph=evidence_graph
        )
        result_nodes.extend(expansion_nodes)
    
    return result_nodes
```

### 6.3 BFS扩展算法

```python
async def _bfs_expand(
    seed_ids: List[str],
    parent_node: EvidenceNode,
    evidence_graph: EvidenceGraph
) -> List[EvidenceNode]:
    """
    BFS多跳扩展算法
    
    输入:
        seed_ids: 种子节点ID列表
        parent_node: 父节点
        evidence_graph: 证据图
    
    输出:
        List[EvidenceNode]: 推理链节点列表
    """
    # 1. BFS遍历
    subgraph = await neo4j_client.bfs_traverse(
        start_node_ids=seed_ids,
        max_hops=self.max_hops,
        limit_per_hop=self.limit_per_hop
    )
    
    if not subgraph.get("nodes"):
        return []
    
    # 2. 构建推理链
    chains = self._build_reasoning_chains(subgraph, seed_ids)
    
    # 3. 转换为证据节点
    result_nodes = []
    for i, chain in enumerate(chains):
        chain_text = self._chain_to_text(chain)
        confidence = self._compute_chain_confidence(chain)
        
        node = evidence_graph.add_evidence(
            evidence=Evidence(
                content=chain_text,
                content_type="reasoning_chain",
                source="knowledge_graph",
                metadata={
                    "chain_index": i,
                    "chain_length": len(chain.get("nodes", [])),
                    "seed_entities": seed_ids[:3],
                    "depth": chain.get("depth", 0)
                }
            ),
            belief=Belief(
                content=f"KG reasoning chain (depth={chain.get('depth', 0)})",
                confidence=confidence,
                source_agent="retrieval_agent"
            ),
            intent=Intent(...),
            parent_node_ids=[parent_node.node_id],
            relation=EdgeRelation.DERIVED_FROM,
            tags=["kg_chain", f"depth_{chain.get('depth', 0)}"]
        )
        result_nodes.append(node)
    
    return result_nodes
```

### 6.4 推理链构建算法

```python
def _build_reasoning_chains(
    subgraph: Dict[str, Any],
    seed_ids: List[str]
) -> List[Dict[str, Any]]:
    """
    从BFS子图构建推理链
    
    输入:
        subgraph: BFS遍历结果
        seed_ids: 种子节点ID列表
    
    输出:
        List[Dict]: 推理链列表
    """
    nodes = subgraph.get("nodes", [])
    if not nodes:
        return []
    
    chains = []
    
    # 为每个种子节点构建一条链
    for seed_id in seed_ids:
        chain_nodes = [n for n in nodes if n.get("id") == seed_id]
        remaining = [n for n in nodes if n.get("id") != seed_id]
        connected = chain_nodes + remaining[:self.limit_per_hop]
        
        if connected:
            chains.append({
                "nodes": connected,
                "seed": seed_id,
                "depth": min(self.max_hops, len(connected))
            })
    
    # 如果没有链, 创建一条包含所有节点的链
    if not chains and nodes:
        chains.append({
            "nodes": nodes,
            "seed": seed_ids[0] if seed_ids else "unknown",
            "depth": self.max_hops
        })
    
    return chains
```

### 6.5 置信度计算算法

```python
@staticmethod
def _compute_chain_confidence(chain: Dict[str, Any]) -> float:
    """
    计算推理链置信度
    
    启发式: 链越短越可靠
    
    输入:
        chain: 推理链字典
    
    输出:
        float: 置信度(0.0-1.0)
    """
    depth = chain.get("depth", 1)
    return round(0.95 ** max(depth, 1), 3)
```

## 7. CascadeFuser详细设计

### 7.1 级联融合算法

```python
async def fuse(
    query: str,
    evidence_graph: EvidenceGraph,
    breadth_nodes: List[EvidenceNode],
    depth_nodes: List[EvidenceNode]
) -> List[EvidenceNode]:
    """
    级联融合算法
    
    多轮迭代融合, 逐步完善证据
    
    输入:
        query: 原始查询
        evidence_graph: 证据图
        breadth_nodes: 广度检索节点(向量检索)
        depth_nodes: 深度检索节点(KG检索)
    
    输出:
        List[EvidenceNode]: 融合节点列表
    """
    all_source_nodes = breadth_nodes + depth_nodes
    fused_nodes = []
    
    for round_idx in range(self.max_rounds):
        logger.info("cascade_round_start", round=round_idx + 1, source_node_count=len(all_source_nodes))
        
        # 1. 收集证据文本
        evidence_texts = self._collect_evidence_texts(all_source_nodes)
        if not evidence_texts:
            break
        
        # 2. LLM融合
        try:
            fusion_result = await self._llm_fuse(query, evidence_texts)
        except Exception as e:
            logger.error("cascade_fusion_llm_failed", round=round_idx, error=str(e))
            break
        
        # 3. 计算置信度
        completeness = fusion_result.get("completeness_score", 0.5)
        relevance = fusion_result.get("relevance_score", 0.5)
        combined_confidence = (completeness + relevance) / 2.0
        
        # 4. 创建融合节点
        parent_ids = [n.node_id for n in all_source_nodes]
        fused_node = evidence_graph.add_evidence(
            evidence=Evidence(
                content=fusion_result.get("fused_summary", ""),
                content_type="fused_evidence",
                source="cascade_fuser",
                metadata={
                    "round": round_idx + 1,
                    "relevance": relevance,
                    "completeness": completeness,
                    "gaps": fusion_result.get("gaps", []),
                    "reasoning": fusion_result.get("reasoning", "")
                }
            ),
            belief=Belief(...),
            intent=Intent(...),
            parent_node_ids=parent_ids,
            relation=EdgeRelation.FUSED_INTO,
            tags=["fused", f"cascade_round_{round_idx + 1}"]
        )
        fused_nodes.append(fused_node)
        
        # 5. 提前终止检查
        if completeness >= 0.85:
            logger.info("cascade_early_stop", round=round_idx + 1, completeness=completeness)
            break
        
        # 6. 下一轮使用融合节点作为输入
        all_source_nodes = [fused_node] + all_source_nodes
    
    logger.info("cascade_fusion_complete", rounds=len(fused_nodes))
    return fused_nodes
```

### 7.2 LLM融合算法

```python
async def _llm_fuse(
    query: str,
    evidence_texts: List[str]
) -> Dict[str, Any]:
    """
    使用LLM进行融合
    
    输入:
        query: 原始查询
        evidence_texts: 证据文本列表
    
    输出:
        Dict: 融合结果字典
    """
    # 1. 限制上下文长度
    evidence_block = "\n---\n".join(evidence_texts[:20])
    
    # 2. 构建提示
    messages = [
        SystemMessage(content=load_prompt("cascade_fusion_system")),
        HumanMessage(
            content=f"Query: {query}\n\nEvidence fragments:\n{evidence_block}"
        )
    ]
    
    # 3. 调用LLM
    response = await llm_service.call(messages, prompt_name="cascade_fusion_system")
    content = response.content.strip()
    
    # 4. 解析JSON
    if "```" in content:
        content = extract_json_from_markdown(content)
    
    try:
        return json.loads(content)
    except json.JSONDecodeError:
        # 降级: 返回非结构化结果
        return {
            "fused_summary": content,
            "relevance_score": 0.5,
            "completeness_score": 0.5,
            "gaps": [],
            "reasoning": "Failed to parse structured output"
        }
```

### 7.3 证据文本收集算法

```python
@staticmethod
def _collect_evidence_texts(nodes: List[EvidenceNode]) -> List[str]:
    """
    从证据节点提取文本内容
    
    输入:
        nodes: 证据节点列表
    
    输出:
        List[str]: 证据文本列表
    """
    texts = []
    for node in nodes:
        content = node.evidence.content
        if content and content.strip():
            conf = node.belief.confidence
            texts.append(f"[confidence={conf:.2f}] {content}")
    return texts
```

## 8. 错误处理和降级策略总结

### 8.1 错误分类和处理

| 错误类型 | 发生位置 | 降级策略 |
|----------|----------|----------|
| LLM分类失败 | QueryClassifier | 默认QComposition类型, 置信度0.5 |
| LLM分解失败 | QueryDecomposer | 使用原始查询作为单一步骤 |
| 向量检索失败 | VectorRetriever | 跳过向量检索, 继续KG检索 |
| KG检索失败 | KGRetriever | 跳过KG检索, 继续向量检索 |
| 分支检索失败 | TreeExplorer | 记录错误, 继续其他分支 |
| LLM融合失败 | CascadeFuser | 返回原始检索结果, 不进行融合 |
| JSON解析失败 | 所有LLM调用 | 尝试提取JSON, 失败则使用默认值 |

### 8.2 超时控制

- LLM调用超时: 30秒
- 向量检索超时: 10秒
- KG检索超时: 15秒

### 8.3 重试机制

- 网络错误: 自动重试最多3次
- 使用tenacity库实现指数退避
