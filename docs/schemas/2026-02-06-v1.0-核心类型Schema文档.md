# 昊中多Agent系统 — 核心类型Schema文档

**版本**: v1.0  
**日期**: 2026-02-06  
**状态**: 正式版  
**位置**: `app/core/types/`

---

## 1. 概述

核心类型系统是所有层共享的基础数据结构, 定义了Agent间通信的契约. 遵循"类型即文档"原则, 所有字段都有Pydantic验证和描述.

### 1.1 模块结构

```
app/core/types/
├── __init__.py     # 统一导出
├── belief.py       # Belief + BeliefUpdate
├── intent.py       # Intent + IntentType
├── evidence.py     # Evidence + EvidenceNode + EvidenceEdge + EvidenceGraph
├── agent_io.py     # AgentInput + AgentOutput + AgentStatus
└── state.py        # PipelineState + PipelinePhase
```

### 1.2 类型关系图

```
PipelineState (顶层LangGraph状态)
├── evidence_graph: EvidenceGraph
│   ├── nodes: Dict[str, EvidenceNode]
│   │   ├── evidence: Evidence
│   │   ├── belief: Belief
│   │   └── intent: Intent
│   └── edges: List[EvidenceEdge]
├── agent_outputs: List[AgentOutput]
│   └── new_nodes: List[EvidenceNode]
└── messages: List[Message]
```

## 2. Belief 模块 (`belief.py`)

### 2.1 BeliefStatus (枚举)

Agent对一条证据的生命周期状态.

| 值 | 含义 | 触发场景 |
|---|------|---------|
| `ACTIVE` | 当前有效 | 创建时默认值 |
| `REVISED` | 已修订 | 被BeliefUpdate更新后 |
| `RETRACTED` | 已撤回 | 被Agent主动撤回 |

### 2.2 Belief (模型)

Agent对一条信息的置信度表达.

| 字段 | 类型 | 必填 | 默认值 | 约束 | 说明 |
|------|------|------|--------|------|------|
| `belief_id` | str | 否 | uuid4() | | 唯一标识 |
| `content` | str | **是** | | | 自然语言描述(belief的主题) |
| `confidence` | float | **是** | | [0.0, 1.0] | 校准置信度分数 |
| `source_agent` | str | **是** | | | 产出此belief的Agent名称 |
| `supporting_evidence_ids` | List[str] | 否 | [] | | 支持此belief的EvidenceNode ID列表 |
| `status` | BeliefStatus | 否 | ACTIVE | | 生命周期状态 |
| `created_at` | datetime | 否 | now(UTC) | | 创建时间戳 |
| `metadata` | dict | 否 | {} | | 扩展元数据 |

**验证器**: `confidence`自动钳位到[0.0, 1.0]范围.

### 2.3 BeliefUpdate (模型)

不可变的belief修订记录, 由Agent提出, 编排层决定是否采纳.

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `update_id` | str | 否 | uuid4(), 唯一标识 |
| `target_belief_id` | str | **是** | 被修订的belief ID |
| `new_confidence` | float | **是** | 新置信度 [0.0, 1.0] |
| `new_status` | BeliefStatus | 否 | 新状态(None则不变) |
| `reason` | str | 否 | 修订原因 |
| `proposed_by` | str | **是** | 提出修订的Agent |
| `created_at` | datetime | 否 | now(UTC) |

## 3. Intent 模块 (`intent.py`)

### 3.1 IntentType (枚举)

Agent间通信意图的固定分类.

| 分类 | 值 | 含义 | 使用Agent |
|------|---|------|---------|
| **检索** | `RETRIEVE` | 寻找相关信息 | retrieval_agent |
| | `DECOMPOSE_QUERY` | 将查询分解为子查询 | retrieval_agent |
| | `CLASSIFY_QUERY` | QDMR查询分类 | retrieval_agent |
| | `TREE_EXPLORE` | QDMR树形探索 | retrieval_agent |
| | `KG_EXPLORE` | 知识图谱遍历 | retrieval_agent |
| | `CASCADE_FUSE` | 多轮融合检索结果 | retrieval_agent |
| **生成** | `GENERATE` | 产出内容 | generation_agent |
| | `PROPOSE_PLAN` | 提出生成计划(proposals) | generation_agent |
| | `REFINE` | 优化先前的生成 | generation_agent |
| **评估** | `EVALUATE` | 评判质量 | evaluation_agent |
| | `MATCH` | 执行匈牙利匹配 | evaluation_agent |
| | `OPTIMIZE_PROMPT` | 优化prompt | evaluation_agent |
| **编排** | `ROUTE` | Gateway路由决策 | orchestration |
| | `DELEGATE` | 委派子任务 | orchestration |
| | `TERMINATE` | 终止管道 | orchestration |

### 3.2 Intent (模型)

附加在证据或Agent输出上的结构化意图.

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `intent_id` | str | 否 | uuid4(), 唯一标识 |
| `intent_type` | IntentType | **是** | 意图类别 |
| `description` | str | 否 | 自然语言解释(供LLM Agent消费) |
| `parameters` | Dict[str, Any] | 否 | 类型特定的结构化参数 |
| `source_agent` | str | **是** | 声明此意图的Agent |
| `target_agent` | str | 否 | 目标接收Agent (None=广播) |
| `created_at` | datetime | 否 | now(UTC) |

## 4. Evidence 模块 (`evidence.py`)

### 4.1 EdgeRelation (枚举)

证据节点之间的有向关系类型.

| 值 | 含义 | 典型场景 |
|---|------|---------|
| `DERIVED_FROM` | B由A推导而来 | 检索结果 <- 子查询 |
| `SUPPORTS` | A支持B的论点 | 证据 -> 生成内容 |
| `CONTRADICTS` | A与B矛盾 | 冲突检测 |
| `DECOMPOSES_TO` | A被拆解为B | 原始查询 -> 子查询/树步骤 |
| `FUSED_INTO` | A...被融合为B | 检索结果 -> 融合证据 |
| `EVALUATED_BY` | A被B评估 | 生成内容 -> 评估结果 |
| `REFINED_INTO` | A被优化为B | 迭代优化 |

### 4.2 Evidence (模型)

原始证据载荷 — 节点携带的内容.

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content` | str | **是** | 文本内容 |
| `content_type` | str | 否 | 内容类型标识(默认"text") |
| `source` | str | 否 | 来源(文档ID, KG节点, URL等) |
| `metadata` | Dict[str, Any] | 否 | 扩展元数据 |

**content_type 枚举** (非代码层面的枚举, 约定值):

| content_type | 来源Agent | 阶段 | 说明 |
|--------------|-----------|------|------|
| `query` | retrieval | Explore | 根查询节点 |
| `query_classification` | retrieval | Classify | QDMR分类结果 |
| `tree_step` | retrieval | Explore | QDMR分解树步骤 |
| `sub_query` | retrieval | Explore | 子查询 |
| `document_chunk` | retrieval | Explore | RAG检索结果 |
| `kg_match` | retrieval | Explore | KG匹配实体 |
| `reasoning_chain` | retrieval | Explore | KG推理链 |
| `fused_evidence` | retrieval | Explore | Cascade融合结果 |
| `proposal` | generation | Plan | Proposal槽位定义 |
| `generated_content` | generation | Execute | 证据图填空结果 |
| `evaluation_result` | evaluation | Validate | 匈牙利匹配评估 |
| `prompt_optimization` | evaluation | Validate | Prompt优化建议 |

### 4.3 EvidenceNode (模型)

证据图中的原子单元.

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `node_id` | str | 否 | uuid4(), 唯一标识 |
| `evidence` | Evidence | **是** | 实际证据载荷 |
| `belief` | Belief | **是** | Agent对此证据的置信度 |
| `intent` | Intent | **是** | 产出此证据的原因 |
| `created_at` | datetime | 否 | now(UTC) |
| `tags` | List[str] | 否 | 自由标签, 用于过滤 |

**不变量**: 每个节点创建时必须同时指定Belief和Intent.

### 4.4 EvidenceEdge (模型)

两个证据节点之间的有向边.

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `edge_id` | str | 否 | uuid4() |
| `source_node_id` | str | **是** | 源节点ID |
| `target_node_id` | str | **是** | 目标节点ID |
| `relation` | EdgeRelation | **是** | 关系类型 |
| `weight` | float | 否 | 权重(默认1.0) |
| `metadata` | Dict[str, Any] | 否 | 扩展元数据 |

### 4.5 EvidenceGraph (模型)

Append-only证据图容器 — Agent间的共享黑板.

| 字段 | 类型 | 说明 |
|------|------|------|
| `graph_id` | str | uuid4() |
| `nodes` | Dict[str, EvidenceNode] | node_id -> 节点映射 |
| `edges` | List[EvidenceEdge] | 边列表 |
| `created_at` | datetime | 创建时间 |

**核心方法**:

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `add_node(node)` | EvidenceNode | EvidenceNode | 添加节点 |
| `add_edge(edge)` | EvidenceEdge | EvidenceEdge | 添加边(验证两端节点存在) |
| `add_evidence(...)` | evidence, belief, intent, parent_node_ids, relation, tags | EvidenceNode | 便捷方法: 创建节点+边 |
| `get_nodes_by_agent(agent)` | str | List[EvidenceNode] | 按Agent过滤 |
| `get_nodes_by_intent(intent_type)` | IntentType | List[EvidenceNode] | 按IntentType过滤 |
| `get_children(node_id)` | str | List[EvidenceNode] | 获取子节点 |
| `get_parents(node_id)` | str | List[EvidenceNode] | 获取父节点 |
| `get_leaf_nodes()` | | List[EvidenceNode] | 获取叶节点 |
| `get_high_confidence_nodes(threshold)` | float | List[EvidenceNode] | 获取高置信度节点 |
| `summary()` | | Dict | 图统计摘要 |

**不变量**: 单次管道运行内append-only, Agent只能新增, 不能删除.

## 5. AgentIO 模块 (`agent_io.py`)

### 5.1 AgentStatus (枚举)

Agent执行退出状态.

| 值 | 含义 | 后续处理 |
|---|------|---------|
| `SUCCESS` | 完全成功 | 正常推进到下一阶段 |
| `PARTIAL` | 部分成功 | 可继续, 但结果不完整 |
| `NEEDS_MORE_INFO` | 信息不足 | 可能需要回退或补充 |
| `ERROR` | 执行出错 | 错误处理/回退 |

### 5.2 AgentInput (模型)

Worker Agent的标准输入信封.

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `query` | str | **是** | | 当前查询或子任务描述 |
| `evidence_graph` | EvidenceGraph | **是** | | 共享证据图(只读快照) |
| `context` | Dict[str, Any] | 否 | {} | Agent特定的上下文参数 |
| `conversation_history` | List[Dict] | 否 | [] | 最近对话消息 |
| `max_iterations` | int | 否 | 3 | Agent内部最大迭代次数 |

### 5.3 AgentOutput (模型)

Worker Agent的标准输出信封.

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `agent_name` | str | **是** | | 产出此输出的Agent名称 |
| `status` | AgentStatus | 否 | SUCCESS | 执行退出状态 |
| `new_nodes` | List[EvidenceNode] | 否 | [] | 新增的证据节点 |
| `belief_updates` | List[BeliefUpdate] | 否 | [] | 对已有belief的修订提案 |
| `summary` | str | 否 | "" | 人类可读的执行摘要 |
| `metrics` | Dict[str, float] | 否 | {} | Agent特定的度量(延迟, token数等) |
| `error_message` | str | 否 | None | 错误消息 |
| `created_at` | datetime | 否 | now(UTC) | 时间戳 |

## 6. PipelineState 模块 (`state.py`)

### 6.1 PipelinePhase (枚举)

管道状态机阶段.

| 值 | 含义 | 对应节点 |
|---|------|---------|
| `EXPLORE` | 检索阶段(QDMR分类+树形探索) | retrieval_agent |
| `FREEZE` | 上下文快照 | freeze_context |
| `PLAN` | 生成计划(Proposal DAG) | plan_phase |
| `EXECUTE` | 内容生成(Slot填空) | generation_agent |
| `VALIDATE` | 评估验证(匈牙利匹配) | evaluation_agent |
| `DONE` | 完成 | assemble_output |
| `ROLLBACK` | 回滚 | rollback_phase |
| `HUMAN_REVIEW` | HITL人工审核 | human_review |

### 6.2 PipelineState (模型)

LangGraph全局状态, 流经整个编排图.

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `messages` | list | [] | LangChain消息列表(add_messages自动合并) |
| `query` | str | "" | 当前用户查询 |
| `evidence_graph` | EvidenceGraph | 新实例 | 共享证据图 |
| `agent_outputs` | List[AgentOutput] | [] | 所有Agent执行结果的有序日志 |
| `current_phase` | str | "explore" | 当前管道阶段 |
| `next_agent` | str | None | Gateway设置的下一个路由目标 |
| `iteration_count` | int | 0 | 全局迭代计数器 |
| `max_iterations` | int | 10 | 迭代硬上限 |
| `rollback_count` | int | 0 | 回滚次数 |
| `max_rollbacks` | int | 1 | 回滚硬上限 |
| `context_manifest` | Dict | {} | Freeze阶段的上下文清单 |
| `plan_dag` | List[Dict] | [] | Plan阶段的Proposal步骤列表 |
| `validation_feedback` | str | "" | Validate阶段的反馈(回滚时使用) |
| `final_output` | str | "" | 最终生成的响应文本 |
| `metadata` | Dict | {} | 任意元数据(user_id, session_id等) |

## 7. 表现层Schema (`app/presentation/schemas/`)

### 7.1 请求Schema (`request.py`)

#### ChatRequest

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `query` | str | **是** | min_length=1 | 用户查询 |
| `session_id` | str | 否 | | 会话ID(不填自动UUID) |
| `user_id` | str | 否 | | 用户标识(默认anonymous) |
| `metadata` | Dict | 否 | {} | 额外元数据 |
| `max_iterations` | int | 否 | 1-50, 默认10 | 最大管道迭代 |

#### HumanReviewRequest

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `session_id` | str | **是** | | 暂停管道的会话ID |
| `action` | str | **是** | approve/reject/edit | 审核动作 |
| `feedback` | str | 否 | "" | 人工反馈文本 |
| `edits` | Dict | 否 | None | 直接编辑(action=edit时) |

### 7.2 响应Schema (`response.py`)

#### ChatResponse

| 字段 | 类型 | 说明 |
|------|------|------|
| `session_id` | str | 会话ID |
| `response` | str | 最终生成的回答 |
| `evidence_summary` | Dict | 证据图统计摘要 |
| `pipeline_metrics` | Dict | 各Agent的执行度量 |
| `intermediate_steps` | List[IntermediateStep] | 中间产物列表 |
| `phase_completed` | str | 最终阶段(默认"done") |

#### IntermediateStep

| 字段 | 类型 | 说明 |
|------|------|------|
| `agent` | str | Agent名称 |
| `label` | str | 步骤标签(如"0. Classify: QDMR查询分类") |
| `nodes` | List[IntermediateNode] | 该步骤的证据节点列表 |

#### IntermediateNode

| 字段 | 类型 | 说明 |
|------|------|------|
| `node_id` | str | 节点ID |
| `content` | str | 内容(截断至800字符) |
| `content_type` | str | 内容类型 |
| `source_agent` | str | 来源Agent |
| `confidence` | float | 置信度 |
| `intent` | str | 意图描述 |
| `tags` | List[str] | 标签 |
| `metadata` | Dict | 元数据(排除embedding等大型字段) |

#### PipelineStatusResponse

| 字段 | 类型 | 说明 |
|------|------|------|
| `session_id` | str | 会话ID |
| `current_phase` | str | 当前阶段 |
| `iteration_count` | int | 迭代次数 |
| `is_waiting_for_human` | bool | 是否等待人工审核 |
| `evidence_summary` | Dict | 证据图摘要 |
| `agent_outputs` | List[Dict] | Agent执行结果 |
