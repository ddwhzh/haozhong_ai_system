## 1. 概述

QDMR(Question Decomposition Meaning Representation)是检索Agent的查询分类和分解基础. 本文档描述QDMR相关的数据结构定义.

---

## 2. QType (枚举)

QDMR查询分类类型. 位于 `app/agents/retrieval/query_classifier.py`.

```python
class QType(str, Enum):
    Q_SELECT = "QSelect"
    Q_FILTER = "QFilter"
    Q_CHAIN = "QChain"
    Q_COMPOSITION = "QComposition"
    Q_COMPARISON = "QComparison"
    Q_AGGREGATION = "QAggregation"
    Q_BOOLEAN = "QBoolean"
    Q_UNION = "QUnion"
```

### 2.1 类型说明表

| QType | 含义 | QDMR算子映射 | 典型查询示例 |
|-------|------|-------------|-------------|
| **QSelect** | 简单事实查询 | select, project | "什么是知识图谱?" |
| **QFilter** | 条件过滤查询 | filter, discard | "哪些图数据库支持分布式?" |
| **QChain** | 链式推理查询 | 多步select->filter->project | "发明Transformer的团队后来做了什么?" |
| **QComposition** | 组合查询 | project + 嵌套步骤 | "解释X并说明其应用" |
| **QComparison** | 比较查询 | comparison | "BERT和GPT的区别?" |
| **QAggregation** | 聚合/排序查询 | aggregate, sort, arithmetic | "列出最常用的图神经网络" |
| **QBoolean** | 是否判断查询 | boolean | "Neo4j支持全文检索吗?" |
| **QUnion** | 联合/交叉查询 | union, intersection | "KG在医疗和金融的应用" |

## 3. StrategyConfig (数据类)

检索策略配置, 由QType决定. 位于 `app/agents/retrieval/query_classifier.py`.

```python
@dataclass
class StrategyConfig:
    primary_strategy: str       # "rag", "kg", or "both"
    fallback_strategy: str      # "kg", "rag", or "both"
    max_decomposition_depth: int
    backtrack_threshold: float
```

### 3.1 QType -> StrategyConfig 默认映射

| QType | primary_strategy | fallback_strategy | max_decomposition_depth | backtrack_threshold |
|-------|------------------|-------------------|------------------------|-------------------|
| QSelect | rag | kg | 2 | 0.4 |
| QFilter | rag | kg | 2 | 0.4 |
| QChain | kg | rag | 3 | 0.4 |
| QComposition | both | both | 3 | 0.4 |
| QComparison | both | both | 3 | 0.4 |
| QAggregation | kg | rag | 2 | 0.4 |
| QBoolean | rag | kg | 1 | 0.4 |
| QUnion | both | both | 3 | 0.4 |

**设计原理**:
- 简单查询(QSelect/QFilter/QBoolean): RAG优先, 向量检索更快更准
- 推理查询(QChain/QAggregation): KG优先, 需要多跳遍历
- 复合查询(QComposition/QComparison/QUnion): 双策略, 两者互补

## 4. ClassificationResult (数据类)

查询分类结果. 位于 `app/agents/retrieval/query_classifier.py`.

```python
@dataclass
class ClassificationResult:
    q_type: QType
    confidence: float
    reasoning: str
    decomposition_hint: List[str]
    strategy: StrategyConfig
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `q_type` | QType | 分类类型 |
| `confidence` | float | 分类置信度 [0.0, 1.0] |
| `reasoning` | str | LLM给出的分类原因 |
| `decomposition_hint` | List[str] | 分解提示(LLM建议) |
| `strategy` | StrategyConfig | 对应的策略配置 |

## 5. TreeStep (数据类)

QDMR分解树中的单个步骤. 位于 `app/agents/retrieval/tree_explorer.py`.

```python
@dataclass
class TreeStep:
    step_idx: int
    question: str
    operator: str
    retrieval_strategy: str
    depends_on: List[int]
    results: List[EvidenceNode] = field(default_factory=list)
    quality: float = 0.0
    explored: bool = False
    backtracked: bool = False
```

### 5.1 字段说明

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `step_idx` | int | LLM输出 | 步骤序号(1-based) |
| `question` | str | LLM输出 | 此步骤的子问题 |
| `operator` | str | LLM输出 | QDMR算子(select/filter/project/aggregate/compare/union/intersect/sort/boolean) |
| `retrieval_strategy` | str | LLM输出 | 建议检索策略("rag"/"kg"/"both") |
| `depends_on` | List[int] | LLM输出 | 依赖的前置步骤索引列表 |
| `results` | List[EvidenceNode] | 运行时 | 此步骤的检索结果 |
| `quality` | float | 运行时 | 分支质量(结果置信度均值) |
| `explored` | bool | 运行时 | 是否已探索完成 |
| `backtracked` | bool | 运行时 | 是否触发了回退 |

### 5.2 QDMR算子说明

| operator | 含义 | 典型用法 |
|----------|------|---------|
| `select` | 选择实体/信息 | "找到X是什么" |
| `filter` | 条件过滤 | "在#1中筛选满足条件Y的" |
| `project` | 投影属性 | "获取#1的属性Z" |
| `aggregate` | 聚合统计 | "统计#1中的数量" |
| `compare` | 比较 | "比较#1和#2的差异" |
| `union` | 合并 | "合并#1和#2的结果" |
| `intersect` | 交集 | "找到#1和#2的共同点" |
| `sort` | 排序 | "将#1按照属性Z排序" |
| `boolean` | 判断 | "判断#1是否满足条件Y" |

## 6. 配置项

| 环境变量 | 类型 | 默认值 | 说明 |
|---------|------|--------|------|
| `RETRIEVAL_BACKTRACK_THRESHOLD` | float | 0.4 | 分支质量回退阈值 |
| `RETRIEVAL_MAX_BRANCH_RETRIES` | int | 1 | 每步最大回退次数 |
| `RETRIEVAL_MAX_TREE_DEPTH` | int | 3 | 最大树深度(QDMR步骤数上限) |
| `RETRIEVAL_MAX_SUB_QUERIES` | int | 5 | 最大子查询/步骤数 |
| `RETRIEVAL_TOP_K` | int | 10 | 向量检索top-k |
| `RETRIEVAL_KG_MAX_HOPS` | int | 3 | KG BFS最大跳数 |
| `RETRIEVAL_CASCADE_ROUNDS` | int | 3 | Cascade融合轮数 |
